# 8.7 退回业务管理

> 所属模块：8. 院内SPD业务扩展模块
> 来源：院内SPD系统产品需求文档.md

## 8.7.1 功能概述

补充科室退库、负数账反消耗、散货库存隔离、隔离退供应商等节点。

## 8.7.2 功能架构

```
退回业务管理
├── 科室退库申请
├── 科室退库审核
├── 负数账反消耗
├── 散货库存隔离
├── 隔离退供应商申请
└── 隔离退供应商审核
```

## 8.7.3 科室退库申请

科室二级库 → 中心库的退库申请（区别于"采购退货：库房 → 供应商"）：

| 字段 | 必填 | 说明 |
|------|------|------|
| 退库单号 | 自动 | TK + YYYYMMDD + 序号 |
| 退库科室 | 是 | 自动带入 |
| 退库类型 | 是 | 多余退库 / 临近效期退库 / 错领退库 / 损坏退库 / 不良事件退库 |
| 退库明细 | 是 | 商品、批号、数量、原申领单号 |
| 退库原因 | 是 | 文本 |
| 附件 | 否 | 照片 / 单据 |

## 8.7.4 科室退库审核

中心库审核员审核退库申请：

| 审核项 | 规则 |
|--------|------|
| 商品状态 | 完整可二次使用 → 直接退库；破损/过效 → 走报损 |
| 批号一致性 | 批号必须与原申领批号一致 |
| 时效性 | 退库申请须在领用后 N 天内（系统配置） |
| 数量合理性 | 不能超过原申领量 |

| 审核结果 | 后置动作 |
|----------|----------|
| 通过-入库 | 退回中心库可用库存 |
| 通过-隔离 | 退入隔离库存（待进一步处理） |
| 驳回 | 退回科室自行处理 |

## 8.7.5 负数账反消耗

针对"已消耗但实际未使用"的散货、手术材料或按明细结算物资进行反向冲销（科室申领消耗后退回，需冲销原消耗记录）。定数包误操作且实物完整恢复原包的反消耗不走本节行级部分反冲规则，按 8.5.7 "定数包全生命周期与反消耗规则"处理。

| 场景 | 说明 |
|------|------|
| 手术取消 | 消耗已记账但手术未做 |
| 错误消耗 | 误扫导致重复消耗 |
| 退货回冲 | 退回中心库后需冲销原消耗 |

| 字段 | 必填 | 说明 |
|------|------|------|
| 反消耗单号 | 自动 | FX + YYYYMMDD + 序号 |
| 关联消耗单 | 是 | 必关联原消耗单 |
| 反冲明细 | 是 | 行级反冲，可全行/部分数量 |
| 反冲原因 | 是 | 必填 |
| 关联退库单 | 否 | 与 8.7.3 退库单联动 |
| 财务处理 | 自动 | 自动生成红字凭证 |

**审批：** 反消耗对账期已结算的消耗须经财务复核。

**与定数包反消耗的区别：**

| 类型 | 适用对象 | 数量口径 | 库存恢复 | 结算处理 |
|------|----------|----------|----------|----------|
| 散货负数账反消耗 | 散货、手术材料、可明细退回物资 | 行级全量/部分数量 | 退回可用或隔离库存 | 已结算走财务复核/红字凭证 |
| 定数包反消耗恢复 | 误操作且实物完整的定数包 | 整包一正一反事件 | 科室审批后恢复原科室定数包库存 | 已结算生成次月红冲明细，不修改历史结算单 |

## 8.7.6 散货库存隔离

| 触发条件 | 说明 |
|----------|------|
| 退回散货 | 8.7.4 审核选择"通过-隔离" |
| 厂家通知召回 | 同批号自动转入隔离 |
| 不良事件涉及 | 同批号同 UDI 自动隔离 |
| 临近过期 | 系统配置阈值内自动隔离 |

| 操作 | 说明 |
|------|------|
| 库存标识 | 隔离库存独立显示，不参与可用库存 |
| 隔离原因 | 必录 |
| 隔离货位 | 物理隔离位 |
| 处理方向 | 销毁 / 退供应商 / 解除隔离 |

## 8.7.7 隔离退供应商申请

| 字段 | 必填 | 说明 |
|------|------|------|
| 申请单号 | 自动 | LF + YYYYMMDD + 序号 |
| 退货供应商 | 是 | 自动带入 |
| 退货原因 | 是 | 召回 / 不良事件 / 质量问题 / 临近效期 |
| 退货明细 | 是 | 隔离库存中的批号/数量/UDI |
| 附件 | 否 | 召回函、检测报告 |

## 8.7.8 隔离退供应商审核

| 节点 | 审批人 |
|------|--------|
| 初审 | 库管主任 |
| 复审 | 质控人员（关键质量问题） |
| 终审 | 运营管理员 |

审核通过后：库存自隔离区出库 → 生成退货出库单 → 财务发起退货红字结算 → 同步通知供应商。
