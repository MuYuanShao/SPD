# AI助手接入

助手通过已认证的 `/api/ai-assistant/chat` 调用院内模型，支持文本、多轮对话和PNG/JPEG/WebP图片（每张最多2MB）。模型列表接口为 `/api/ai-assistant/models`，代理模型服务器的 `/api/tags`。

后端默认配置：

- `SPD_AI_BASE_URL=http://172.16.2.157:11434`（根地址，不加 `/v1`）
- `SPD_AI_MODEL=qwen3-vl:8b`
- `SPD_AI_TIMEOUT_MS=120000`

修改环境变量后重启后端。浏览器通过项目 `/api` 访问后端，无需直接访问模型服务器或配置模型跨域。对话仅在当前页面内存中保存，不写入数据库。助手不读取业务数据库或执行业务操作；库存、收费及追溯结果须通过业务页面查询。

部署后在后端所在主机访问模型 `/api/tags`，确认安装 `qwen3-vl:8b`，然后登录系统打开AI医护助手，发送文字、上传图片并验证连续提问。网络不可达或推理超时时，助手显示错误并恢复待发送内容。
