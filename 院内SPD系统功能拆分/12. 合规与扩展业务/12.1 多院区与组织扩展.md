# 12.1 多院区与组织扩展

> 所属模块：12. 合规与扩展业务
> 来源：院内SPD系统产品需求文档.md

## 12.1.1 功能概述

支持总院 + N 分院的多院区组织模型，满足跨院区数据隔离、统一总账、跨院区调拨、院领导合并报表等需求。

## 12.1.2 多院区组织模型

```
集团总院
├── 院区A（总院）
│   ├── 中心库（一级库）
│   ├── 临床科室（二级库 × N）
│   └── 手术室（手术备货库）
├── 院区B（分院1）
│   ├── 中心库
│   └── 临床科室
└── 院区C（分院2）
    ├── 中心库
    └── 临床科室
```

| 维度 | 隔离规则 |
|------|----------|
| 商品目录 | 全集团共享，价格 / 准入按院区差异化 |
| 供应商 | 全集团共享，配送范围按院区授权 |
| 合同 | 院区独立或集团统一签约，价格生效范围明确 |
| 库存 | 院区独立，不可越级查看 |
| 用户 | 默认所属一个院区，可授权多院区 |
| 审批 | 院区内部闭环，跨院区调拨触发双院区审批 |
| 财务 | 按法人主体决定独立核算或集团合并 |

## 12.1.3 院区基础信息维护

| 字段 | 必填 | 说明 |
|------|------|------|
| 院区编码 | 是 | YQ + 3 位 |
| 院区名称 | 是 | - |
| 院区类型 | 是 | 总院 / 分院 / 院外驻点 / 联盟成员 |
| 上级院区 | 否 | 形成树状结构 |
| 法人主体 | 是 | 独立法人 / 共用集团法人 |
| 财务核算 | 是 | 独立核算 / 集团核算 |
| 院区地址 | 是 | - |
| 启用状态 | 是 | 启用 / 停用 |
| 启用日期 | 是 | - |

## 12.1.4 跨院区库存调拨

跨院区调拨与同院区库房间调拨（12.4.3）边界明确：跨院区涉及法人主体、票据流转，必须双院区审批。

| 字段 | 必填 | 说明 |
|------|------|------|
| 调拨单号 | 自动 | KQ + YYYYMMDD + 序号 |
| 调出院区 / 库房 | 是 | - |
| 调入院区 / 库房 | 是 | - |
| 调拨原因 | 是 | 紧急借调 / 库存均衡 / 集采分发 / 退回总院 |
| 调拨明细 | 是 | 商品、批号、数量、UDI |
| 价格处理 | 是 | 内部成本价 / 调拨价 / 不计价（同法人时） |
| 票据需求 | 是 | 是否需开内部调拨单 / 跨法人发票 |
| 物流方式 | 是 | 院区班车 / 第三方物流 / 自取 |

**审批流程：**
```
[调出院区运营] → [调出院区主任] → [调入院区运营] → [调入院区主任]
    → [集团总部审核（金额>阈值或跨法人）] → [出库] → [物流]
    → [调入院区收货] → [双方对账]
```

## 12.1.5 院区数据隔离与共享规则

| 数据类型 | 默认范围 | 集团合并规则 |
|----------|----------|--------------|
| 库存 | 院区内 | 集团驾驶舱可查看汇总 |
| 消耗 | 院区内 | 月报合并按院区维度展示 |
| 合同 | 院区内或集团 | 集团合同对所有院区生效 |
| 报表 | 院区内 | 院领导可切换"本院/全集团" |
| 审计日志 | 全集团统一 | 按院区过滤查询 |
| 用户权限 | 院区内 | 可显式授权多院区 |
