# 8.8 手术临床管理

> 所属模块：8. 院内SPD业务扩展模块
> 来源：院内SPD系统产品需求文档.md

## 8.8.1 功能概述

补充手术全流程节点：开始/取消手术、领出/归还手术材料、寄售/跟台归集、临时单合并、手术单确认、术后调整、未确认查询、耗用汇总、先收费后消耗确认。

## 8.8.2 功能架构

```
手术临床管理
├── 手术单管理
│   ├── 开始/取消手术
│   ├── 手术单确认
│   ├── 手术单查询
│   └── 先收费后消耗方式手术单确认
├── 手术材料管理
│   ├── 领出手术材料
│   └── 归还手术材料
├── 寄售/跟台归集
├── 临时手术单向接口手术单合并
├── 术后处理
│   ├── 术后调整预留节点
│   └── 手术未确认耗材查询
└── 手术耗用汇总
```

## 8.8.3 开始 / 取消手术

| 操作 | 说明 |
|------|------|
| 开始手术 | 扫描手术单/患者腕带 → 状态：进行中；锁定关联耗材库存 |
| 取消手术 | 状态：已取消；释放锁定耗材；如已领出材料 → 触发归还流程 |
| 暂停 | 状态：暂停（手术中断），保留锁定 |

## 8.8.4 领出手术材料

| 字段 | 说明 |
|------|------|
| 领料单号 | LL + YYYYMMDD + 序号 |
| 关联手术单 | 是 |
| 领料类型 | 计划领料 / 临时加领 |
| 领料明细 | UDI 扫码（高值）/ 批量（低值）/ 手术包 |
| 领料人 | 巡回护士 |
| 状态 | 已领出 / 已归还 / 已使用 |

## 8.8.5 归还手术材料

| 操作 | 说明 |
|------|------|
| 扫码归还 | 扫描 UDI / 包号 → 归还到手术包待清点 |
| 部分归还 | 一张领料单可分多次归还 |
| 归还原因 | 未使用 / 损坏 / 错领 |
| 库存变化 | 完整可用 → 回手术备货库；损坏 → 隔离 |

## 8.8.6 寄售 / 跟台归集

寄售 / 跟台耗材（供应商提供，使用后再结算）的归集管理：

| 业务对象 | 说明 |
|----------|------|
| 寄售耗材 | 供应商寄存在医院的耗材，使用后才入采购 |
| 跟台耗材 | 厂家代表跟台带来的耗材 |

| 字段 | 必填 | 说明 |
|------|------|------|
| 归集单号 | 自动 | JX + YYYYMMDD + 序号 |
| 关联手术单 | 是 | - |
| 寄售/跟台类型 | 是 | 寄售 / 跟台 |
| 供应商 | 是 | - |
| 厂家代表 | 跟台必填 | 入院登记 |
| 耗材明细 | 是 | UDI、批号、数量、规格 |
| 状态 | - | 已带入 / 已使用 / 已带出 / 已转采购 |

**业务流程：**
```
[术前供应商带入耗材登记] → [手术中扫码使用] → [术后清点]
    → [已用部分→自动转采购入库+消耗] → [未用部分→带出登记]
    → [生成应付/应收明细]
```

## 8.8.7 临时手术单向接口手术单合并

来自 HIS 的"临时手术单"（手术中临时安排）与 SPD 接口推送的"标准手术单"合并：

| 场景 | 处理 |
|------|------|
| HIS 推送临时手术 | SPD 自动建立临时手术单（标记为 TEMP） |
| 转为正式 | 接口手术单到达后，按患者ID + 手术时间匹配 |
| 自动合并 | 系统提示匹配项，运营/手术室确认后合并 |
| 合并后处理 | 临时单的耗材使用自动归并到正式单 |

| 字段 | 说明 |
|------|------|
| 临时单号 | TEMP + YYYYMMDD + 序号 |
| 接口手术单号 | 来自 HIS |
| 合并状态 | 待匹配 / 已匹配 / 已合并 / 已驳回 |
| 操作日志 | 记录合并人、时间 |

## 8.8.8 手术单确认

手术结束后对手术单耗材使用做最终确认：

| 字段 | 说明 |
|------|------|
| 手术单号 | - |
| 实际使用耗材 | UDI 扫码记录 |
| 未用归还 | 自动从领料中扣除 |
| 患者关联 | 强制 |
| 主刀医生确认 | 电子签字 |
| 巡回护士复核 | 电子签字 |
| 计费同步 HIS | 自动 |

确认后状态变为"已确认"，触发：消耗扣减 + HIS 计费 + UDI 追溯写入。

## 8.8.9 手术单查询

| 查询字段 | 说明 |
|----------|------|
| 手术单号 / 患者 / 主刀医生 / 手术名称 | 多维 |
| 手术日期范围 | 必填 |
| 状态 | 待手术 / 进行中 / 已完成 / 已确认 / 已取消 |
| 耗材使用情况 | 已用品类、金额 |
| 是否含高值 / 寄售 / 跟台 | - |
| 是否已确认 | - |

## 8.8.10 术后调整预留节点

预留接口，用于术后修正手术单耗材数据（医保审核驳回、患者投诉、错扫等）：

| 操作 | 说明 |
|------|------|
| 调整类型 | 数量增减 / 商品增删 / 替换批号 / 退回未用 |
| 审批 | 主刀医生 + 运营管理员 |
| 后置 | 自动联动负数账反消耗 + HIS 重新计费 |
| 留痕 | 强制留痕，永久不可删除 |

## 8.8.11 手术未确认耗材查询

定时巡查"手术已结束但耗材未确认"的异常：

| 查询字段 | 说明 |
|----------|------|
| 手术结束时间 | 距今 ≥ N 小时（系统配置默认 4 小时） |
| 未确认明细 | 已领出但未扫码确认的 UDI |
| 责任人 | 巡回护士 / 主刀医生 |
| 提醒方式 | 系统消息 / 短信 |

## 8.8.12 手术耗用汇总

| 维度 | 输出 |
|------|------|
| 按手术类型 | 各类手术平均耗材成本 |
| 按主刀医生 | 医生耗材消耗排行 |
| 按科室 | 科室手术耗材消耗 |
| 按时间段 | 月/季/年趋势 |
| 高值耗材占比 | 高值 / 低值耗材消耗结构 |

## 8.8.13 先收费后消耗方式手术单确认

医保审核要求"先收费、后消耗"的手术单（区别于一般"实领实消"）：

| 流程 | 说明 |
|------|------|
| 1. 计划领料 | 按手术单计划领出，库存「锁定」但不消耗 |
| 2. 推送 HIS 收费 | 按计划耗材推送 HIS 自动计费 |
| 3. 手术中使用 | UDI 扫码记录实际使用 |
| 4. 术后确认 | 实际使用 = 已收费 → 直接消耗；< 已收费 → 触发负数账反消耗+退费；> 已收费 → 补费再消耗 |
| 5. 消耗扣减 | 仅按实际使用量扣减库存 |

> 该确认节点必须在医保规则下闭环，差异行强制人工确认。
