# 12.2 合同与招采管理

> 所属模块：12. 合规与扩展业务
> 来源：院内SPD系统产品需求文档.md

## 12.2.1 功能概述

补全采购前置环节：招标、集采、询价比价、合同管理、价格对照与两票制流向追溯，与第 5.1 采购管理形成完整链条。

## 12.2.2 功能架构

```
合同与招采管理
├── 招标管理
│   ├── 公开招标 / 邀请招标
│   ├── 竞争性谈判 / 竞争性磋商
│   └── 单一来源采购
├── 集采订单管理
│   ├── 国家集采
│   ├── 省级集采
│   └── GPO 联盟采购
├── 询价比价
├── 合同管理
│   ├── 框架协议 / 年度合同 / 项目合同 / 附加协议
│   ├── 价格变更
│   └── 合同到期预警
├── 集采价 / 挂网价对照
└── 两票制流向追溯
```

## 12.2.3 招标管理

| 字段 | 必填 | 说明 |
|------|------|------|
| 招标编号 | 自动 | ZB + YYYYMMDD + 序号 |
| 招标类型 | 是 | 公开 / 邀请 / 竞争性谈判 / 竞争性磋商 / 单一来源 |
| 招标名称 | 是 | - |
| 标的范围 | 是 | 商品类别、品规清单 |
| 预算金额 | 是 | - |
| 报名截止时间 | 是 | - |
| 开标时间 | 是 | - |
| 评标专家 | 是 | 至少 5 人，奇数 |
| 评标办法 | 是 | 综合评分法 / 最低评标价法 / 性价比法 |
| 招标文件 | 是 | PDF 附件，需双方签章 |
| 中标结果 | 自动 | 中标供应商 / 中标价 / 中标公告 |
| 状态 | - | 草稿 / 公示中 / 评标中 / 已中标 / 已签约 / 流标 |

**招标流程：**
```
[需求科室申报] → [运营管理员立项] → [院级招标办审核]
    → [发布招标公告] → [供应商报名/递交标书]
    → [开标/评标（专家库抽取）] → [中标公示 N 天]
    → [异议处理] → [发中标通知书] → [合同签订]
    → [纳入采购目录]
```

## 12.2.4 集采订单管理

针对国家 / 省级带量采购、GPO 联盟采购：

| 字段 | 必填 | 说明 |
|------|------|------|
| 集采批次号 | 是 | 国家或省级文件号 |
| 集采类型 | 是 | 国家集采 / 省级集采 / 跨省联盟 / GPO |
| 集采品种 | 是 | 关联商品目录 |
| 中标供应商 | 是 | 多家中标时按医院选择 |
| 中标价 | 是 | 系统强制使用，不可修改 |
| 协议采购量 | 是 | 医院上报量 |
| 协议周期 | 是 | 通常 1-3 年 |
| 完成进度 | 自动 | 已采购量 / 协议量 |
| 完成预警 | 自动 | 进度 < 80% 触发预警，距期末 < 90 天 |
| 替代品规则 | 是 | 集采产品缺货时是否允许替代 |

> 合同/集采价格作为商品目录采购单价维护和采购分析的参考依据。实际结算以验收入库生成的批次单价及已形成事实的原单价为准；未完成协议量到期前 90 天触发强制催采。

## 12.2.7 合同价格变更

| 场景 | 处理 |
|------|------|
| 集采降价 | 关联外网采购平台获取的集采目录，按目录更新时间与合同价格更新时间对比生成变价公告，经采购管理员确认后价格生效 |
| 协商调价 | 双方签附加协议，新价格生效需运营总监审批 |
| 招标重定 | 新招标中标后旧合同终止，新合同启用 |
| 应急涨价 | 原厂涨价文件 + 院领导特批 |

变更记录强制留痕，旧价格历史可追溯，对未付款订单按"订单日期价格"或"调整后价格"二选一处理。外网采购平台目录更新后，系统需按目录更新时间、物料编码、供应商、规格型号与合同明细进行匹配，对存在价格差异的合同形成待确认变价清单，并在确认后生成公告展示。

## 12.2.8 合同到期预警

| 阶段 | 提前 N 天 | 通知对象 |
|------|-----------|----------|
| 一级提醒 | 90 天 | 采购管理员 |
| 二级提醒 | 60 天 | 采购管理员 + 运营总监 |
| 三级提醒 | 30 天 | 采购总监 + 院领导 |
| 紧急预警 | 7 天 | 全采购团队 + 强制日报 |

到期前未续签的合同自动进入"宽限期"（默认 15 天），宽限期内不允许新增订单，仅允许已下未收订单的尾款结算。

| 字段 | 说明 |
|------|------|
