# 4.1 商品目录管理

> 所属模块：4. 主数据管理模块
> 来源：院内SPD系统产品需求文档.md

## 4.1.1 功能概述

商品目录管理是SPD系统的核心基础数据模块，管理医院内所有可采购、可使用的医疗耗材、试剂、设备等商品信息。商品目录是采购、库存、科室申领等业务的数据基础。前端菜单按"商品目录"父节点组织，下设"待审批目录"与"医院目录"两个子节点：待审批目录承接新品准入、字段变更、资质更新和价格调整审批；医院目录维护审批通过后的院内正式可用商品。

## 4.1.3 商品分类体系

| 一级分类 | 二级分类示例 | 三级分类示例 |
|----------|-------------|-------------|
| 耗材 | 注射类、输液类、敷料类、导管类、手术器械 | 一次性注射器、留置针、输液器、纱布、导尿管 |
| 试剂 | 生化试剂、免疫试剂、分子诊断 | 血糖试纸、尿酸试纸 |

## 4.1.4 核心功能

| 功能 | 说明 |
|------|------|
| 商品列表查询 | 支持多维度搜索：名称、编码、品牌、供应商、分类、状态、价格区间、效期等 |
| 新增商品 | 分Tab页填写：基本信息、价格信息、资质信息、仓储信息 |
| 编辑商品 | 修改商品信息，需走变更审批流程（关键字段） |
| 删除商品 | 逻辑删除，已产生业务数据的商品不可删除 |
| 启用/停用 | 控制商品是否可采购和使用 |
| 导入/导出 | 支持Excel批量导入导出 |
| 批量修改 | 支持批量调整分类、状态、是否定数管理等非唯一字段，关键字段需进入待审批目录 |
| 变更记录 | 查询商品字段变更历史、操作人、审批单据和生效时间 |
| 查看附件 | 查看商品资质附件（注册证、检验报告等） |

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 是否高值耗材 | 开关 | 是 | 默认否 |

| 储存条件 | 下拉选择 | 否 | 常温/冷藏/冷冻/避光 |

**是否定数管理变更规则：**

- 高值耗材和冷链试剂不纳入定数包模板，需根据验收入库自动生成的唯一码或填写的 UDI 进行管控。
- `是否定数管理` 是定数业务硬准入开关；业务配置不能突破该硬约束。只有 `是否定数管理 = 是` 的商品可进入定数包模板、自动成包、初始化打包和定数安全量计算。
- 新建/发布定数包模板、新打包时，系统必须校验包内商品 `是否定数管理 = 是`。
- 当 `是否定数管理` 从“是”改为“否”时，系统弹窗提示：`请确认该商品是否存在定数包库存。保存后将禁止生成新的定数包业务，历史已打包库存仍允许继续消耗。`
- 商品改为非定数管理后，历史定数包可继续消耗、反消耗、召回、盘点和结算，但不再生成新模板、新打包、自动成包、定数安全量补包和新的定数缺货任务。
- 当 `是否定数管理` 从“否”改为“是”时，只影响后续业务；历史散货库存不自动成包，需由授权人员通过“历史散货初始化打包”功能人工发起。
- 用户确认后保存并记录操作日志；系统不自动召回、不自动解包。

**采购单价变更规则：**

- 商品目录 `采购价/采购单价` 是验收入库生成系统批次单价的来源字段，不直接代表历史库存批次的当前单价。
- 商品目录采购单价变更会影响后续新验收入库批次单价，不自动改变历史已验收批次单价。
- 商品目录采购单价变更必须审批/复核并强制留痕，记录变更前价格、变更后价格、变更原因、操作人、审批/复核人和生效时间。
- 已验收数据的批次单价固化；除调价管理按批次调价或退货重新采购外，不因商品目录价格变化而改变。
- 验收入库时若最新商品目录采购单价与采购订单预估单价或单据预览价不同，系统弹窗提醒并记录验收确认人、确认时间、原预览价、最新采购单价和验收单号，但不阻断验收。
