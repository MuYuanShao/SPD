# 4.2 待审批商品目录管理

> 所属模块：4. 主数据管理模块
> 来源：院内SPD系统产品需求文档.md

## 4.2.1 功能概述

待审批商品目录管理是SPD系统中商品准入的核心流程模块。供应商提交新品申请或现有商品信息变更后，需经过审批流程才能正式进入商品目录。

前端菜单名称为"待审批目录"，与"医院目录"共同归属于"商品目录"父节点。审批通过的数据写入医院目录；驳回或退回修改的数据保留在待审批目录中继续跟踪。

## 4.2.2 业务流程

```
[供应商提交新品申请/变更申请] → [进入待审批池] → [审批人员初审]
    → [审批人员复审/多级审批] → [商品正式入库到商品目录]
    → [驳回：退回供应商，说明原因]
    → [退回修改：退回供应商补充资料]
```

## 4.2.3 审批状态

| 状态 | 颜色 | 说明 |
|------|------|------|
| 待初审 | 橙色 | 等待初审人员审批 |
| 初审通过 | 蓝色 | 初审已通过，等待复审 |
| 初审驳回 | 红色 | 初审被驳回 |
| 待复审 | 紫色 | 等待复审人员审批 |
| 复审通过 | 绿色 | 复审通过，即将入库 |
| 复审驳回 | 红色 | 复审被驳回 |
| 退回修改 | 黄色 | 退回供应商补充资料 |

## 4.2.4 申请类型

| 类型 | 说明 |
|------|------|
| 新品准入 | 新商品首次进入商品目录 |
| 信息变更 | 商品信息（价格、规格等）变更 |
| 价格调整 | 采购价格调整 |
| 资质更新 | 注册证、许可证、授权文件等资质材料更新 |
| 停用申请 | 商品停用申请 |
