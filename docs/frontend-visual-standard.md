# SPD 前端布局与视觉规范

## 布局

以浏览器可用宽度为准，包含侧栏占用和浏览器缩放影响。页面和网格子项允许收缩；宽表格只在自身容器内滚动，不能通过裁剪隐藏字段。主从布局在内容宽度不足时改为上下排列。

公共适配入口是 frontend/src/styles/responsive-medical.css，由 main.ts 在旧样式之后加载。新增页面应优先复用 PageHeader、PaginationControls 和现有公共样式类，避免添加新的固定页面宽度。

筛选字段最小宽度 180px、表单字段最小宽度 240px，使用自适应网格。输入、选择、普通按钮统一 36px，图标按钮 36×36px；数量步进器整体使用同一高度。

正文和表格 14px、页面标题 20px；控件圆角 6px、面板圆角 8px；控件间距 8px、字段间距 12px、面板内边距与页面区块间距 16px。

## 医疗视觉

使用青绿主色 #0f766e、白色面板、浅灰背景和深色正文。主操作明确，次操作轻量；危险操作使用红色并保留文字。状态不能只依赖颜色。避免大面积装饰渐变、重阴影和业务页顶部大概览。

中文使用本地微软雅黑、苹方及系统字体；数量和金额使用等宽数字。键盘焦点必须可见，控件尺寸不能随屏幕宽度整体缩放。

## 验收

检查 1280×720、1366×768、1440×900、1920×1080、2560×1440，以及 125%/150% 浏览器缩放。验证侧栏手动展开后在同一断点内缩放不会重新折叠。

重点覆盖宽表格末列和末行、筛选换行、分页、长表单和弹窗、主从布局、驾驶舱。构建执行 npm --prefix frontend run build；真实业务验证执行 npm run test:smoke:business-ui，并通过环境变量提供有效测试账号。

本次构建通过。真实业务验证使用启动脚本提供的账号时被“用户名或密码错误”阻断；完整页面视觉验收仍需有效账号，不应将构建成功等同于所有页面验收通过。
