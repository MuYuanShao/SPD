# 7.3 SaaS化与配置中心

> 所属模块：7. 运营支撑模块
> 来源：院内SPD系统产品需求文档.md

## 7.3.1 功能概述

SaaS化与配置中心用于支撑集团医院、多院区、多租户、差异化模块订阅和运行时参数配置。系统通过租户、模块订阅、配置项、配置发布、灰度回滚和变更审计，将医院差异化规则从代码中抽离，支撑多租户隔离和配置化交付。

## 7.3.2 核心能力

| 能力 | 说明 |
|------|------|
| 租户管理 | 维护集团、医院、院区等租户身份、部署模式和数据驻留策略 |
| 模块订阅 | 管理租户可用模块、版本、配额和功能开关 |
| 配置项管理 | 支持系统级、租户级、院区级、科室级、仓库级、模块级、用户级配置 |
| 配置发布 | 支持草稿、提交、审批、发布、灰度、回滚、归档 |
| 配置审计 | 配置变更写入配置审计、统一审计日志和审计双写队列，支持追溯 |
| 密钥引用 | 敏感配置不保存明文，仅保存 KMS/Vault 引用，发布前校验 KMS 引用状态 |

## 7.3.3 配置优先级

```text
用户级 > 模块级 > 仓库级 > 科室级 > 院区级 > 租户级 > 系统级 > 默认值
```

权限类配置按用户/角色/岗位优先；业务策略类配置按“更细粒度优先”命中，配置中心需能展示最终生效值和来源配置。

**业务策略配置优先级：**

| 优先级 | 配置范围 |
|--------|----------|
| 1 | 商品 + 科室 |
| 2 | 商品 + 库房 |
| 3 | 商品 + 院区 |
| 4 | 商品 + 医院 |
| 5 | 商品分类 + 科室 |
| 6 | 商品分类 + 库房 |
| 7 | 商品分类 + 院区 |
| 8 | 商品分类 + 医院 |
| 9 | 科室 |
| 10 | 库房 |
| 11 | 院区 |
| 12 | 医院 |
| 13 | 租户/集团 |
| 14 | 系统默认 |

**配置填写要求：**

| 字段 | 要求 |
|------|------|
| 配置类型 | 必填，如补货策略、定数包系数、散货替代、反消耗审批、日清策略、调价策略 |
| 适用范围 | 必填，医院、院区、库房、科室、商品分类、商品等 |
| 适用对象 | 必填，选择具体院区、库房、科室或商品 |
| 配置值 | 必填，按配置类型填写 |
| 生效方式 | 必填，实时生效 / 定时生效 |
| 生效时间 | 定时生效必填，实时生效默认为当前时间 |
| 失效时间 | 可选 |
| 风险等级 | 系统按配置类型识别，可由授权人员调整 |
| 变更原因 | 必填 |
| 审批要求 | 按风险等级决定直接生效、复核或审批 |
| 配置状态 | 草稿 / 待审批 / 已生效 / 已驳回 / 已失效 / 已作废 |
| 附件依据 | 高风险配置建议必填 |

**配置冲突与生效规则：**

- 同一配置类型、同一适用范围、同一对象、同一时间段不允许存在多条生效配置。
- 上下级配置可同时存在，细粒度配置覆盖粗粒度配置。
- 未来待生效配置也参与冲突检测；已失效、已驳回、已作废配置不参与当前命中。
- 配置变更支持实时生效和定时生效。定时配置到点后，按配置类型触发重算、下一轮计算或权限变更，并记录生效日志。
- 配置审批驳回后保留草稿和驳回原因，当前生效配置不变。
- 配置按医院、院区、库房、科室、商品分类、商品等范围灰度生效；前台允许授权用户新增、修改、停用和复制配置。

**配置命中说明：**

关键业务页面需提供“查看配置来源”入口，点击后展示最终生效值、配置类型、来源层级、来源配置编号、适用对象、生效时间、失效时间、是否覆盖上级配置、上级配置值、最近变更人和审批状态。普通查看配置来源不记录查看日志。普通业务单据导出/打印默认不展示配置来源；审批类或审计导出可选择包含配置来源。

## 7.3.5 P0 配置项目录基线

以下配置项为一期上线必须具备的业务策略配置基线。配置项需支持前台新增、修改、停用、复制、实时生效、定时生效、灰度范围、冲突检测、风险等级和命中说明。

| 配置项 | 默认值/默认策略 | 适用范围 | 风险等级 | 生效动作 |
|--------|-----------------|----------|----------|----------|
| 补货任务生成模式 | 生成补货建议 | 医院/院区/库房/科室/商品 | 中 | 下一轮补货计算 |
| 补货定时任务频率 | 每日固定时间窗 | 医院/院区/库房/科室/商品 | 中 | 定时任务调度 |
| 补货数量策略 | 补到目标或最大 | 科室/商品/定数包包族 | 中 | 下一轮补货计算 |
| 缺货登记排序规则 | 紧急等级 + 登记时间 | 医院/院区/科室/商品 | 中 | 下一轮来货匹配 |
| 散货替代定数包缺货 | 默认不允许 | 医院/院区/科室/商品 | 高 | 未满足缺货登记下一轮匹配 |
| 定数包自动成包模式 | 待确认打包任务 | 库房/商品 | 高 | 后续验收入库/打包 |
| 定数包系数 | 按商品模板维护 | 商品/科室/库房 | 高 | 重算未确认打包任务 |
| 未确认打包任务超时策略 | 提醒，不自动释放 | 库房/商品 | 中 | 超时提醒/释放 |
| 标签补打权限与原因 | 必填原因并留痕 | 角色/库房/科室 | 中 | 立即生效 |
| 日清后反消耗流程 | 科室审批 + SPD 复核 | 医院/院区/科室 | 高 | 后续反消耗申请 |
| 批次单价调价审批 | 财务复核必选 | 医院/院区/商品 | 高 | 审批通过后生成价格版本 |
| 批号/效期批量调整审批 | 必须审批 | 医院/院区/商品 | 高 | 审批通过后更新追溯属性 |
| 盘亏计入科室成本 | 计入 | 医院/院区/科室 | 高 | 后续盘亏复核 |
| PDA 离线强一致限制 | 禁止审批/反消耗/召回/结算 | 系统/医院/院区 | 高 | 立即生效 |
| 召回/隔离补货触发 | 定时任务扫描触发 | 医院/院区/科室/商品 | 中 | 下一轮补货计算 |

高风险配置按风险等级进入复核或审批；审批驳回保留草稿和驳回原因。配置变更不回改已完成业务事实，只影响后续业务、未完成任务或按规则触发重算。
