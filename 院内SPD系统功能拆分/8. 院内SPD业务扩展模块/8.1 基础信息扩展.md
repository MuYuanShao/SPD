# 8.1 基础信息扩展

> 所属模块：8. 院内SPD业务扩展模块
> 来源：院内SPD系统产品需求文档.md

## 8.1.1 功能概述

基础信息扩展用于补充 SPD 院内业务所需的字典与对照数据，是上层业务流程（请货、收货、上架、出库、消耗、结算）的运行前提。

## 8.1.2 功能架构

```
基础信息扩展
├── 产品对应医院统计分类维护
├── 产品对应计量单位维护
├── 库房管理
│   ├── 实物库房维护
│   ├── 虚拟库房维护
│   ├── 库房按科室统计要求分类
│   └── 库房上下级对照维护
├── 货位管理
│   ├── 货位维护
│   └── 散货引导货位维护
├── 库房权限
│   ├── 人员库房权限维护（列表）
│   └── 人员库房权限维护（树形）
├── 手持终端配置
│   ├── 手持岗位维护
│   ├── 手持岗位权限
│   └── 手持人员对应岗位
├── HIS对照
│   ├── HIS科室与SPD库房对照
│   └── HIS人员与SPD人员对照
├── 批号管理
│   ├── 批号新增
│   └── 批号修改
└── 系统关键配置项维护
```

## 8.1.3 产品对应医院统计分类维护

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 统计分类编码 | 输入框 | 是 | 5-20 字符，唯一 |
| 统计分类名称 | 输入框 | 是 | 2-50 字符 |
| 上级分类 | 级联选择 | 否 | 支持多级 |
| 分类用途 | 多选 | 是 | 卫健委上报/院内成本核算/医保对账/绩效考核 |
| 关联产品 | 弹窗多选 | 否 | 支持批量绑定/解绑 |
| 状态 | 开关 | 是 | 启用/停用 |

> 与商品三级分类（耗材/试剂/设备）解耦，仅作为统计维度。一个产品可同时绑定多个统计分类。

## 8.1.4 产品对应计量单位维护

| 字段 | 必填 | 说明 |
|------|------|------|
| 基本单位 | 是 | 与商品 `单位` 字段一致（个/盒/瓶等） |
| 采购单位 | 是 | 与基本单位换算 |
| 申领单位 | 是 | 通常等于基本单位 |
| 消耗单位 | 是 | 通常等于最小拆分单位 |
| 换算关系 | 是 | 1 箱 = N 盒 = M 个，多级换算链 |
| 是否拆零 | 是 | 拆零商品出库使用最小单位 |

**业务规则：**
- 同一产品可维护"采购→入库→申领→消耗"四级单位换算链。
- 拆包业务依赖此换算关系自动计算拆零数量。

## 8.1.5 库房维护与虚拟库房

| 库房类型 | 说明 | 典型用途 |
|----------|------|----------|
| 实物库房（中心库） | SPD 中心仓 | 总库存、采购入库 |
| 实物库房（科室二级库） | 科室物理库房 | 科室收货、消耗扣减 |
| **虚拟库房** | 不对应物理空间 | 在途库存、隔离库存、寄售库存、定数包待拆库 |
| 应急库房 | 紧急调拨用 | 突发事件调用 |

**库房表单字段：**

| 字段 | 必填 | 说明 |
|------|------|------|
| 库房编码 | 是 | 唯一 |
| 库房名称 | 是 | 2-50 字符 |
| 库房类型 | 是 | 实物/虚拟/应急 |
| 上级库房 | 否 | 支持多级，参与「库房上下级对照维护」 |
| 所属院区 | 是 | 主院区/东院区等 |
| 关联科室 | 否 | 二级库需关联科室 |
| 库房负责人 | 是 | 用户选择 |
| 是否参与统计 | 是 | 默认参与 |
| 统计要求分类 | 多选 | 院领导驾驶舱/科主任看板/财务核算/物流绩效 |

## 8.1.6 货位维护与散货引导货位

**货位维护：**

| 字段 | 必填 | 说明 |
|------|------|------|
| 货位编码 | 是 | A 区-01 排-02 列-03 层 形式 |
| 所属库房 | 是 | 关联库房 |
| 货位类型 | 是 | 整件位/散货位/高值位/冷藏位/隔离位 |
| 容量上限 | 否 | 件数或体积 |
| 关联产品 | 否 | 固定货位绑定的产品 |
| 状态 | 是 | 启用/锁定/停用 |

**散货引导货位维护：**

| 字段 | 必填 | 说明 |
|------|------|------|
| 产品编码 | 是 | 唯一对应一个产品 |
| 引导货位 | 是 | 散货拆零优先存放位 |
| 备用货位 | 否 | 主货位满后启用 |
| 最低存量 | 是 | 低于该值触发补散货 |
| 最高存量 | 是 | 高于该值停止补散货 |

> 在「散货收货」与「申领单散货打包出库转补货」节点中，系统按引导货位自动分配上架/补散货位。

## 8.1.7 人员库房权限维护

**列表视图：** 矩阵式表格，行为人员、列为库房，支持单元格批量勾选「查看 / 入库 / 出库 / 盘点 / 调拨 / 管理员」。

**树形视图：** 左树为「库房树」，右侧为「该库房可访问人员清单」，支持拖拽。

| 操作 | 说明 |
|------|------|
| 批量授权 | 选择多人 + 多库房一次性授权 |
| 权限继承 | 上级库房权限自动继承到下级（可覆盖） |
| 权限审计 | 每次变更产生审计日志 |
| 临时授权 | 支持设置有效期，到期自动回收 |

## 8.1.8 手持终端配置

**手持岗位维护：**

| 岗位编码 | 岗位名称 | 默认权限 |
|----------|----------|----------|
| HD-RECV | 收货员 | 收货扫码、打包扫码 |
| HD-SHELF | 上架员 | 客户端标签上架、货位绑定 |
| HD-PICK | 拣货员 | 拣配作业、出库配送 |
| HD-COUNT | 盘点员 | 手持盘点、差异上报 |
| HD-DEPT | 科室收货员 | 科室收货、日清确认 |

**手持岗位权限：** 控制 PDA 端可见菜单与按钮（按钮级权限）。

**手持人员对应岗位：** 一名人员可绑定多个岗位，登录 PDA 后切换岗位上下文。

## 8.1.9 HIS 对照管理

**HIS 科室与 SPD 库房对照：**

| 字段 | 说明 |
|------|------|
| HIS 科室编码 | 来自 HIS 系统 |
| HIS 科室名称 | 来自 HIS 系统 |
| SPD 库房编码 | 关联 8.1.5 库房 |
| 计费方式 | 实领实结/实销实结/月结 |
| 同步状态 | 已同步/待同步/同步失败 |

**HIS 人员与 SPD 人员对照：**

| 字段 | 说明 |
|------|------|
| HIS 工号 | 来自 HIS 系统 |
| HIS 姓名 | 来自 HIS 系统 |
| SPD 用户ID | 关联 `sys_user` |
| 角色映射 | 医生/护士/库管 → SPD 角色 |

> 高值耗材计费推送、消耗回写 HIS 均依赖此对照。

## 8.1.10 批号管理

**批号新增：**

| 字段 | 必填 | 说明 |
|------|------|------|
| 商品编码 | 是 | 关联商品 |
| 批号 | 是 | 1-30 字符 |
| 生产日期 | 是 | - |
| 有效期至 | 是 | - |
| 注册证号 | 否 | 自动带入 |
| 供应商 | 是 | - |
| 入库单号 | 否 | 收货时回填 |

**批号修改：** 仅允许修改"生产日期、有效期、注册证号"，不允许修改批号本身（修改时强制留痕，需运营管理员审批）。

## 8.1.11 系统关键配置项维护

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 安全库存预警系数 | 1.2 | 实际安全库存 = 配置值 × 历史均消耗 |
| 效期预警天数 | 90 | 临近效期提醒 |
| 拆零是否自动 | 是 | 出库时自动拆零 |
| 定数包补货阈值 | 0.5 | 已消耗 ≥ 50% 触发补货 |
| 高值出库强制扫码 | 是 | - |
| 散货补货周期 | 1 天 | 散货引导货位补货扫描周期 |
| 手持自动登出 | 30 分钟 | PDA 无操作自动登出 |
| HIS 推送方式 | 实时 | 实时/定时/手动 |
| 不良事件强制上报 | 是 | - |

> 关键配置项变更需「运营管理员发起 → 院领导审批」，所有变更纳入审计日志。
