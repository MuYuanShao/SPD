# 5.1 采购管理

> 所属模块：5. 供应链业务模块
> 来源：院内SPD系统产品需求文档.md

## 5.1.1 功能概述

采购管理是SPD供应链的核心环节，连接供应商和医院库存。系统支持从需求汇总、采购计划、订单生成到订单跟踪的全流程管理。

## 5.1.3 需求来源

| 来源 | 说明 | 触发条件 |
|------|------|----------|
| 库存补货 | 库存低于安全库存 | 定时任务扫描 |
| 科室申领 | 科室物资消耗 | 科室发起申领 |
| 新品采购 | 新商品首次采购 | 新品准入后 |
| 临时采购 | 紧急物资需求 | 手动创建 |
| 协议采购 | 年度协议执行 | 按协议周期 |

## 5.1.4 智能补货公式

```
建议采购量 = 安全库存 + 预测消耗量 × 采购周期 - 当前库存 - 在途数量
预测消耗量 = 近3个月平均日消耗量 × 系数
```

## 5.1.6 采购审核规则

| 条件 | 审核人 | 时限 |
|------|--------|------|
| 金额 ≤ 5万 | 采购主管 | 1工作日 |
| 5万 < 金额 ≤ 50万 | 采购主管 + 财务 | 2工作日 |
| 金额 > 50万 | 采购主管 + 财务 + 院领导 | 3工作日 |
