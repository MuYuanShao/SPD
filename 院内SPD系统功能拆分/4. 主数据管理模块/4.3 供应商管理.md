# 4.3 供应商管理

> 所属模块：4. 主数据管理模块
> 来源：院内SPD系统产品需求文档.md

## 4.3.1 功能概述

供应商是SPD供应链的核心参与方，医院需要对供应商进行全生命周期管理，包括准入审批、资质管理、合同管理、绩效评估等。

## 4.3.2 功能架构

```
供应商管理
├── 供应商列表
├── 供应商准入申请
├── 供应商审批流程
├── 供应商详情
├── 供应商编辑
├── 供应商启停
├── 资质管理
├── 合同管理
├── 联系人管理
├── 银行账户管理
├── 绩效评估
├── 供应商分级
├── 导入导出
└── 附件管理
```

## 4.3.3 供应商审批流程

```
[提交申请] → [资质初审] → [现场考察] → [资质复审] → [合同签署] → [系统建档] → [完成]
    ↑           ↓             ↓             ↓             ↓            ↓
    └────── [退回修改] ← [退回修改] ← [退回修改] ← [退回修改] ──────┘
```

## 4.3.4 供应商等级

| 等级 | 说明 | 合作策略 |
|------|------|----------|
| A | 优秀供应商 | 优先合作，可免检 |
| B | 良好供应商 | 正常合作 |
| C | 合格供应商 | 加强监管 |
| D | 不合格供应商 | 限期整改或淘汰 |

## 4.3.5 供应商表单字段

| 字段 | 必填 | 校验规则 |
|------|------|----------|
| 供应商名称 | 是 | 2-100字符，不可重复 |
| 统一社会信用代码 | 是 | 18位，校验规则 |
| 供应商类型 | 是 | 生产商/配送商/代理商/经销商 |
| 营业执照 | 是 | PDF/JPG/PNG，最大10MB |
| 经营许可证 | 是 | PDF/JPG/PNG，最大10MB |
| 联系人姓名 | 是 | 2-50字符 |
| 联系电话 | 是 | 手机号或固话格式 |
