## 修复内容

1. **发票表和采购权限元数据缺失**：现场数据库存在迁移历史与实际结构不一致的情况。新增 V100 补偿迁移，恢复发票表、科室权限关系表及缺失菜单/动作元数据；不修改历史迁移，不新增角色授权，不启用已停用权限。仅凭旧校验和无法证明实际结构完整，未推断历史不一致的操作来源。
2. **启动与部署校验不足**：新增共享数据库结构校验，在后端开放监听前及部署验证命令中检查关键表列与权限元数据。缺失时阻止启动；校验本身不建表、不授予权限，也不要求人为禁用的权限必须启用。
3. **结算货型受当前目录属性影响**：新增 V101，保存结算明细货型快照，生成、查询和数量分类统一使用快照。历史回填优先依据收费来源、定数包关系、批次追溯关系及批次形成前已审批目录信息；证据不足的高值记录标记为“待核对货型”，前端支持展示和筛选。迁移不调整数量、单价和金额。后续生成同时读取批次追溯关系，覆盖自动与手动补生成路径。
4. **服务层数据权限拒绝被映射为服务器错误**：统一异常处理明确返回 HTTP 403 和业务码 403，避免深层 SELF 数据范围拒绝落入通用 500 处理。回归覆盖本人采购可见、他人详情/跟踪/附件不可见。
5. **回归夹具和断言不符合业务口径**：修正跨模板散货重复统计的旧断言；高值 MySQL 测试使用隔离库内完整供应商资料；补充历史货型快照、补偿迁移不改变角色授权和金额等验证。A/B 脚本的异常断言收紧至 4xx，业务 500 不再视为预期拒绝。
