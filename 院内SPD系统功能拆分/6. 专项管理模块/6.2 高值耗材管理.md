# 6.2 高值耗材管理

> 所属模块：6. 专项管理模块
> 来源：院内SPD系统产品需求文档.md

## 6.2.1 功能概述

高值耗材（High-Value Consumables）是指单价较高、直接作用于人体、需要严格追溯的医用耗材，如心脏支架、人工关节、起搏器、介入耗材等。

## 6.2.4 准入流程

```
[科室申请] → [医务部审核] → [设备科审核] → [伦理审查] → [院长审批] → [准入完成]
```

## 6.2.5 高值耗材入库要求

- 必须扫描UDI码
- 必须验证注册证有效性
- 必须记录批次号和序列号
- 必须验证效期

## 6.2.6 高值耗材出库要求

- 必须扫描UDI码
- 必须关联手术申请
- 必须关联患者信息
- 必须医生确认

## 6.2.8 当前产品定位与实现基线（2026-07-13）

旧“高值耗材管理”页面当前定位为**收费耗材明细查询**。它不是库存事件页面，也不以科室取出作为计费完成依据。

业务时序：

```text
科室领用/手术备货 → 实物待使用 → HIS/手麻/手术系统回传计费
→ SPD 校验外部计费号、追溯码和商品 → FIFO 扣减实际库房库存
→ 写收费记录、库存事件、UDI 追溯事件和审计日志
```

已实现：

- 按患者号/住院号、患者姓名、商品编码、商品名称、日期、UDI、唯一码、供应商、厂家和注册证查询。
- 结果展示医院目录信息、收费数量、单价、金额、患者信息和计费时间。
- 外部计费号具有数据库唯一约束；重复及双线程并发回调返回同一计费结果，库存只扣一次。
- 高值耗材收费与追溯主记录使用 `trace_code_id` 外键关联。
- UDI/唯一码、商品编码、实际扣减库房在扣减前完成一致性和必填校验。
- 页面提供紧凑查询区、横向明细表和分页，不设置顶部大统计卡片。

验收标准：

- [x] 科室领用不触发高值耗材收费扣库。
- [x] 计费回调成功后库存不得为负，并生成不可变库存事件。
- [x] 同一外部计费号并发回调只产生一条收费记录和一次库存扣减。
- [x] 收费详情能够按医院目录、患者和追溯字段组合筛选。
- [x] 页面筛选、分页、空状态和横向滚动通过固定 Playwright 冒烟测试。
- [ ] 完整手术申请、医生确认、术中扫码和术后反记账仍属于后续范围。
- [ ] HIS/手麻厂商协议适配、消息签名、重放队列和人工补偿台仍需建设。
