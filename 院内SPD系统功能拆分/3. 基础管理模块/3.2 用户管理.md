# 3.2 用户管理

> 所属模块：3. 基础管理模块
> 来源：院内SPD系统产品需求文档.md

## 3.2.1 功能概述

用户管理是系统基础权限模块的核心，用于管理系统内所有操作用户的生命周期，包括创建、查询、编辑、禁用/启用、删除、重置密码、分配角色等。

## 3.2.2 页面布局

```
+----------------------------------------------------------+
|  用户管理                                                  |
+----------------------------------------------------------+
|  [搜索区域]                                                |
|  用户名: [________]  状态: [全部▼]  科室: [全部▼]  [查询] [重置] |
+----------------------------------------------------------+
|  [新增用户] [批量删除] [导出Excel]                          |
+----------------------------------------------------------+
|  [数据表格]                                                |
|  □ | 用户名 | 真实姓名 | 科室   | 角色     | 状态 | 操作   |
+----------------------------------------------------------+
|  共 50 条  [1][2][3][4][5]  每页: [10▼]                   |
+----------------------------------------------------------+
```

## 3.2.3 核心功能

| 功能 | 说明 |
|------|------|
| 用户列表查询 | 支持按用户名、真实姓名、状态、科室筛选 |
| 新增用户 | 填写用户名、密码、真实姓名、手机号、所属科室、角色等 |
| 编辑用户 | 修改用户信息，用户名不可修改 |
| 删除用户 | 逻辑删除，不能删除当前登录用户和系统预置管理员 |
| 重置密码 | 将密码重置为默认密码，首次登录强制修改 |
| 分配角色 | 为用户分配一个或多个角色 |

## 3.2.4 用户表单字段

| 字段 | 类型 | 必填 | 校验规则 |
|------|------|------|----------|
| 用户名 | 输入框 | 是 | 2-20字符，字母数字下划线，唯一 |
| 密码 | 密码框 | 是 | 6-20字符 |
| 确认密码 | 密码框 | 是 | 与密码一致 |
| 真实姓名 | 输入框 | 是 | 2-20字符 |
| 手机号 | 输入框 | 否 | 11位手机号格式 |
| 邮箱 | 输入框 | 否 | 邮箱格式 |
| 性别 | 单选 | 否 | 男/女/未知 |
| 所属科室 | 下拉选择 | 是 | 从科室管理获取 |
| 角色 | 多选下拉 | 是 | 至少选一个 |
| 状态 | 开关 | 是 | 启用/禁用 |
