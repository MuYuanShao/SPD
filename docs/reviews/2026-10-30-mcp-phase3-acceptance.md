## 验收发现与修正

大单消息在领取前一直处于 pending、尝试次数为零。上传任务报告数据库异常；领取 SQL 对包含完整 JSON 的行排序。改为仅排序并锁定消息编号，再按主键读取快照，1001 行自动同步随即通过。另将二期异常处理与第三期发送分开，避免前置二期失败跳过第三期。

测试夹具也修正了两处问题：二期空库存用例关闭连接开关后，第三期需显式恢复；DECIMAL 库存数量按 Decimal 读取。没有通过放宽金额校验、截断行数或修改数据库内存参数使测试通过。

浏览器复核发现原 MCP 配置组件未被系统页面引用，已接入“系统配置 → 系统集成”，重新生产构建通过。Chrome 验证计划、结算及带筛选查询使用 `/api/integration/.../phase3` 并返回 200；SPD 同步状态与反馈诊断 `/api/mcp-phase3/status`、`/api/mcp-phase3/feedback` 返回 200。页面验收在独立的 5175/1825 前端端口完成，未改动业务前端实例。
