# 5.3 科室申领

> 所属模块：5. 供应链业务模块
> 来源：院内SPD系统产品需求文档.md

## 当前产品边界（2026-07-13）

- 进入页面首先展示历史科室申领单摘要，包括单号、科室、目标库房、申请人、数量、金额、状态和申请时间。
- 新建申领只能选择当前科室及目标库房有效目录内的商品，不允许直接浏览完整医院目录。
- 申领明细与历史单摘要分离；审批、驳回、拣货、配送和签收按状态机推进。
- 高值耗材的科室领用只代表实物流转，不代表患者计费或最终库存消耗。

### 当前验收基线

- [x] 历史申领单按单据维度分页，不按明细行重复展示。
- [x] 可查询单据明细和目录字段。
- [x] 新建时受科室—库房—商品目录关系约束。
- [x] 配送签收将库存从来源库房转入科室目标库房。
- [ ] 科室退回、撤回和跨院区审批的完整异常路径仍需专项验收。

## 5.3.1 功能概述

科室申领是医院内部物资流转的核心环节，连接科室消耗和SPD中心库。系统支持多种申领模式，满足不同科室的物资需求。

## 5.3.2 功能架构

```

│   ├── 紧急申领

│   └── 模板申领
├── 申领审批
```

## 5.3.3 申领类型

| 类型 | 说明 | 特点 |
|------|------|------|
| 常规申领 | 标准物资申领流程 | 需审批，按流程配送 |
| 紧急申领 | 紧急物资需求 | 绕过正常审批，优先处理，事后补批 |
| 定数包申领 | 按固定数量打包申领 | 简化操作，自动补货 |
| 模板申领 | 保存常用申领组合 | 一键快速申领 |

> 定数包申领仅作为科室端业务入口。定数包模板、安全量、打包标签、事件流水、消耗、反消耗、红冲和 PDA 离线规则以 8.2、8.5 的定数包全生命周期规则为准；本节不单独定义定数包库存和结算口径。

## 5.3.4 申领审批规则

| 条件 | 审批人 | 时限 |
|------|--------|------|
| 金额 ≤ 1000 | 科室主任 | 即时 |
| 1000 < 金额 ≤ 5000 | 科室主任 + SPD主管 | 2小时 |
| 金额 > 5000 | 科室主任 + SPD主管 + 部门领导 | 4小时 |
| 紧急申领 | 事后补批，先配送 | 24小时内 |
