# 5.4 结算对账

> 所属模块：5. 供应链业务模块
> 来源：院内SPD系统产品需求文档.md

## 5.4.1 功能概述

结算对账是SPD供应链管理的重要环节，涉及医院与供应商之间的货款结算、发票管理、财务对账等业务。

```

├── 结算单管理
│   ├── 结算单生成

├── 对账管理
│   ├── 自动对账
```

## 5.4.3 结算单生成方式

| 方式 | 说明 |
|------|------|
| 自动结算 | 按结算周期自动生成 |
| 手动结算 | 手动选择入库单生成 |
| 实销实结 | 按科室消耗数据生成 |

## 5.4.4 结算单状态

| 状态 | 说明 | 操作 |
|------|------|------|
| 草稿 | 草稿 | 编辑、删除、提交 |
| 待审核 | 待审核 | 审核、退回 |
| 已审核 | 已审核 | 发送供应商、取消 |
| 待供应商确认 | 待供应商确认 | 确认、驳回 |
| 已确认 | 已确认 | 发票匹配、付款 |
| 已开票 | 已开票 | 付款 |
| 部分付款 | 部分付款 | 继续付款 |
| 已付款 | 已付款 | 关闭 |
| 已关闭 | 已关闭 | - |
| 已取消 | 已取消 | - |

## 5.4.6 对账结果

| 结果 | 说明 | 处理 |
|------|------|------|
| 完全匹配 | 数量、金额一致 | 自动确认 |
| 数量差异 | 入库数量与订单数量不一致 | 标记差异 |
| 价格差异 | 入库单价与订单单价不一致 | 标记差异 |
| 未匹配 | 有入库单无订单或有订单无入库 | 标记异常 |
