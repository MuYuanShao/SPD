# 12.8 决策支持扩展

> 所属模块：12. 合规与扩展业务
> 来源：院内SPD系统产品需求文档.md

## 12.8.1 功能概述

补全数据大屏、移动审批、自助报表设计器、指标口径字典、数据血缘、报表订阅推送等决策支持节点，与 7.1 报表中心、9.4.13/9.4.14 数据 API、10.14 仪表盘配置形成完整链条。

## 12.8.2 功能架构

```
决策支持扩展
├── 数据大屏 / 驾驶舱
│   ├── 院领导驾驶舱
│   ├── 科室主任看板
│   ├── 财务大屏
│   └── 物流大屏
├── 移动审批 APP / 小程序
├── 自助报表设计器
├── 指标口径字典
├── 数据血缘追溯
└── 报表订阅 / 邮件 / 钉钉推送
```

## 12.8.3 数据大屏 / 驾驶舱

| 大屏类型 | 受众 | 核心组件 |
|----------|------|----------|
| 院领导驾驶舱 | 院长 / 副院长 | 总览 KPI、库存周转、采购趋势、消耗排行、合规预警 |
| 科室主任看板 | 科室主任 | 本科室申领、消耗、库存、预算、医生使用 |
| 财务大屏 | 财务总监 | 应付应收、月度账期、发票认证率、付款执行 |
| 物流大屏 | 物流主管 | 配送实时、车辆位置、签收率、异常 |
| 集团驾驶舱 | 集团领导 | 多院区合并、对比、排名 |

| 大屏组件 | 说明 |
|----------|------|
| KPI 数字 | 大字突出关键指标 |
| 趋势图 | 同比 / 环比 / 实时 |
| 排行榜 | TopN 物品 / 科室 / 医生 |
| 地图 | 多院区地理分布、配送车辆位置 |
| 实时滚动 | 异常 / 召回 / 预警等告警流 |
| 钻取 | 一键下钻到明细 |

**技术规格：**
- 适配 4K / 拼接屏 / 普通显示器
- 实时刷新间隔可配置（默认 5 分钟）
- 支持导出图片 / PDF
- 支持全屏 / 自动轮播多个大屏

## 12.8.4 移动审批 APP / 小程序

| 业务查询 | 库存 / 报表 / 预警 / 召回 |

## 12.8.6 指标口径字典

统一指标定义，避免歧义：

| 字段 | 必填 | 说明 |
|------|------|------|
| 指标编码 | 自动 | ZB + 3 位 |
| 指标名称 | 是 | 如"库存周转率" |
| 指标类型 | 是 | 财务 / 库存 / 采购 / 消耗 / 质量 |
| 业务定义 | 是 | 业务侧描述 |
| 计算口径 | 是 | 数学公式 |
| 数据来源 | 是 | 表 / 字段路径 |
| 计算频率 | 是 | 实时 / 日 / 月 / 季 / 年 |
| 单位 | 是 | 次 / 元 / % / 天 |
| 主管部门 | 是 | 财务 / 运营 / 采购 等 |
| 版本历史 | - | 口径变更留痕 |

> 同名指标在不同报表中必须使用相同口径定义，强制引用本字典。

## 12.8.7 数据血缘追溯

| 维度 | 说明 |
|------|------|
| 字段血缘 | 报表字段 → 主题字段 → 中间表字段 → 源表字段 |
| 表血缘 | 数据集 → 数据集市 → 数据仓库 → 业务库 |
| ETL 血缘 | ETL 任务依赖关系 |
| 应用血缘 | 哪些报表 / 大屏使用了某指标 |

**展示方式：**
- 图谱式血缘可视化（支持上钻 / 下钻）
- 影响分析：源表字段变更时自动列出受影响的下游报表
- 依赖分析：报表运行慢时自动定位上游瓶颈

## 12.8.8 报表订阅 / 推送

| 推送渠道 | 说明 |
|----------|------|
| 邮件 | PDF / Excel 附件 |
| 钉钉 | 卡片消息 + 链接 |
| 企微 | 应用消息 |
| 短信 | 简短指标 |
| APP 推送 | 移动端 APP |

| 字段 | 必填 | 说明 |
|------|------|------|
| 订阅单号 | 自动 | DY + 序号 |
| 订阅人 | 是 | - |
| 报表 / 大屏 | 是 | - |
| 推送频率 | 是 | 每日 / 每周 / 每月 / 实时 |
| 推送时间 | 是 | 如每日 9:00 |
| 推送渠道 | 是 | 见上 |
| 数据范围 | 是 | 默认按订阅人权限 |
| 异常告警 | 否 | 指标超阈值时立即推送 |
