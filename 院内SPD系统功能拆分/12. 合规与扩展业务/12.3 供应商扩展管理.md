# 12.3 供应商扩展管理

> 所属模块：12. 合规与扩展业务
> 来源：院内SPD系统产品需求文档.md

## 12.3.1 功能概述

补全供应商门户、绩效 KPI、资质证照预警、价格调整、客诉与回复等供应商全生命周期能力，与 4.3 供应商管理形成完整链条。

## 12.3.2 功能架构

```
供应商扩展管理
├── 供应商门户（独立 Web 端）
├── 供应商绩效 KPI 评分
├── 资质证照预警
├── 价格调整申请
├── 客诉与回复
└── 黑名单管理
```

## 12.3.3 供应商门户

外网独立 Web 端，供应商自助使用：

| 功能模块 | 说明 |
|----------|------|
| 商品准入申请 | 提交新品申请、查看审批进度（与 4.2 联动） |
| 订单管理 | 查看医院采购订单、确认接单、维护货期 |
| 配送管理 | 主动创建 B2B 配送单（区别于 8.3.3 院方确认侧）、上传物流单号 |
| 物流跟踪 | 实时定位、ETA 预测、异常上报 |
| 对账中心 | 双向对账、差异确认、电子对账单 |
| 发票管理 | 上传发票、查询认证状态、查询付款进度 |
| 资质中心 | 上传 / 续期资质证照、到期提醒 |
| 客诉中心 | 接收客诉、回复处理、上传整改报告 |
| 价格调整申请 | 申请涨价 / 降价 / 新增品规 |
| 公告通知 | 接收医院发布的公告、政策变更 |

**安全要求：**
- API Key + 签名认证（详见 9.3）
- 强制 IP 白名单
- 敏感操作（提交报价 / 发票）双因子认证
- 全部操作纳入审计日志

## 12.3.4 供应商绩效 KPI 评分

| KPI 指标 | 权重 | 计算方式 |
|----------|------|----------|
| 到货及时率 | 25% | (实际及时到货数 / 应到货数) × 100% |
| 数量准确率 | 15% | (1 - 数量差异 / 应到数量) × 100% |
| 质量合格率 | 25% | (合格件数 / 总验收件数) × 100% |
| 退货率 | 10% | (退货金额 / 总采购金额) × 100% |
| 售后响应时间 | 10% | 平均响应小时数（越短越高分） |
| 资质合规性 | 10% | 证照齐全且未过期 = 100，缺失或过期 = 0 |
| 客诉处理及时率 | 5% | (按时回复客诉数 / 总客诉数) × 100% |
| 综合得分 | - | Σ(指标得分 × 权重) |

| 等级 | 得分区间 | 处理 |
|------|----------|------|
| A | ≥ 90 | 优先合作 / 续签优先 |
| B | 80–89 | 正常合作 |
| C | 70–79 | 警告 / 限期整改 |
| D | < 70 | 暂停合作 / 启动黑名单评估 |

**评分周期：** 月度滚动评分 + 季度复审 + 年度总评。

## 12.3.5 资质证照预警

| 证照类型 | 必备 | 预警阈值 |
|----------|------|----------|
| 营业执照 | 是 | 到期前 90/60/30/7 天 |
| 医疗器械经营许可证 | 是 | 到期前 90/60/30/7 天 |
| 体外诊断试剂经营资质 | 试剂供应商必需 | 到期前 90/60/30/7 天 |
| GSP 认证证书 | 是 | 到期前 90/60/30/7 天 |
| 三证合一 / 五证合一 | 是 | - |
| 医疗器械注册证（按品种） | 是 | 到期前 180/90/30 天 |
| 生产许可证（厂家） | 是 | 到期前 180/90/30 天 |
| ISO 体系认证 | 否 | 到期前 90 天 |

**预警动作：**
- 一级预警 → 系统消息 + 邮件给供应商 + 站内提醒
- 二级预警 → 短信 + 邮件 + 系统消息
- 三级预警 → 暂停发起新订单
- 已过期 → 强制冻结，已生效订单走特批

## 12.3.6 价格调整申请

| 字段 | 必填 | 说明 |
|------|------|------|
| 申请单号 | 自动 | TJ + YYYYMMDD + 序号 |
| 申请类型 | 是 | 涨价 / 降价 / 新增品规 / 停产替代 |
| 关联合同 | 是 | - |
| 调整商品 | 是 | 商品 + 规格 |
| 现行价 / 申请价 | 是 | - |
| 涨幅 / 降幅 | 自动 | (申请价 - 现行价) / 现行价 |
| 调整原因 | 是 | 文本 + 附件（原厂涨价函 / 集采降价文件） |
| 生效日期 | 是 | - |
| 状态 | - | 待审 / 通过 / 驳回 |

**审批分级：**
- 涨幅 ≤ 5% → 采购管理员
- 5% < 涨幅 ≤ 10% → 采购总监 + 财务
- 涨幅 > 10% → 院领导特批

## 12.3.7 客诉与回复

| 字段 | 必填 | 说明 |
|------|------|------|
| 客诉单号 | 自动 | KS + YYYYMMDD + 序号 |
| 客诉来源 | 是 | 关联 8.6.5 意见反馈 / 8.6.6 不良事件 / 直接录入 |
| 涉事供应商 | 是 | - |
| 涉事商品 / 批号 | 是 | - |
| 客诉等级 | 是 | 一般 / 重要 / 紧急 |
| 处理时限 | 自动 | 一般 7 天 / 重要 3 天 / 紧急 24 小时 |
| 供应商回复 | 是 | 整改报告 + 附件 |
| 院方确认 | 是 | 已闭环 / 不接受 / 需复查 |
| 影响处理 | - | 是否扣 KPI / 是否进入黑名单 |

## 12.3.8 黑名单管理

| 字段 | 必填 | 说明 |
|------|------|------|
| 黑名单编号 | 自动 | HM + YYYYMMDD + 序号 |
| 供应商 | 是 | - |
| 加入原因 | 是 | KPI 评级 D / 严重客诉 / 资质造假 / 商业贿赂 |
| 加入依据 | 是 | 文件 / 决议 + 附件 |
| 期限 | 是 | 一年 / 三年 / 永久 |
| 加入审批 | 是 | 院领导 + 法务 + 院级招标办 |
| 解除条件 | 否 | - |
| 关联院区 | 是 | 单院区 / 集团 |

> 黑名单生效后，所有采购、招标、合同、配送均自动屏蔽该供应商。
