## 6.3.1 功能概述

冷链试剂对温度敏感，需要在规定的温度范围内储存和运输。温度超标可能导致试剂失效，严重影响检测准确性。

```
├── 数据记录

│   ├── 异常事件记录
│   └── 处理记录
```


## 6.3.5 预警类型

| 预警类型 | 触发条件 | 级别 | 通知方式 |
|----------|----------|------|----------|
| 温度超标 | 温度超出阈值 | 紧急 | 系统+短信+电话 |
| 温度预警 | 温度接近阈值 | 重要 | 系统+短信 |
| 设备离线 | 设备断网/断电 | 紧急 | 系统+短信+电话 |

## 6.3.7 冷链异常处置闭环

冷链异常不能只停留在告警展示，必须形成可关闭、可追溯、可审计的处置闭环。异常来源包括温度超限、温度长时间未更新、设备离线、传感器故障、人工补录温度异常、运输交接异常。

```
[异常触发] → [自动冻结/隔离相关库存] → [通知责任人]
    → [质控判定] → [可用/继续隔离/报损/销毁/退供应商/召回]
    → [生成补货或采购建议] → [关闭异常并归档]
```

| 处置节点 | 系统要求 |
|----------|----------|
| 异常触发 | 记录设备、库位、温度值、持续时长、影响商品/批号/唯一码范围 |
| 自动隔离 | 命中库存进入隔离状态，禁止出库、消耗、结算和调拨 |
| 责任通知 | 按院区、库房、质控、设备责任人分层配置通知策略 |
| 质控判定 | 必须填写判定结论、依据、附件和复核人 |
| 库存处理 | 支持转可用、继续隔离、报损、销毁、退供应商、召回 |
| 补货联动 | 对影响安全库存的商品生成补货建议或紧急采购建议 |
| 关闭归档 | 关闭时校验所有命中唯一码/批号均有处理结果 |

**约束：**
- 冷链异常关闭前，命中的高值耗材、冷链试剂和批号库存不得参与正常业务。
- 设备离线期间补传的温度数据按服务端处理时间入账，但必须标记为离线补传数据。
- 若补传数据证明历史超温，应按当前处理时间触发异常闭环，不反向强制修改已关账数据。
- 异常处置结果需要进入追溯链路，支持按唯一码、批号、设备、库位、院区反查。
