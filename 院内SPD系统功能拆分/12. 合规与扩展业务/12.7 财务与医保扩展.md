# 12.7 财务与医保扩展

> 所属模块：12. 合规与扩展业务
> 来源：院内SPD系统产品需求文档.md

## 12.7.1 功能概述

补全多账套、预算管理、成本中心、保证金质保金、月结反结、DRG / DIP 病种付费、医保目录、医保驳回处理等财务与医保闭环节点，与 5.4 结算对账、8.9 结算与发票形成完整链条。

## 12.7.2 功能架构

```
财务与医保扩展
├── 多账套
├── 预算管理（科室年度耗材预算）
├── 成本中心 / 成本归集
├── 保证金 / 备货金 / 质保金
├── 月结 / 反结 / 结账锁定
├── DRG / DIP 病种付费
├── 医保目录管理
└── 医保驳回处理
```

## 12.7.3 多账套

| 字段 | 必填 | 说明 |
|------|------|------|
| 账套编码 | 自动 | ZT + 3 位 |
| 账套名称 | 是 | 如"总院账套"、"分院 A 账套"、"医保账套" |
| 账套类型 | 是 | 法人主体 / 业务模块 / 合并报表 |
| 关联院区 | 是 | 单个或多个 |
| 关联科室 | 否 | 仅本账套核算的科室 |
| 启用日期 | 是 | - |
| 财务系统对接 | 是 | 金蝶 / 用友 / SAP / 自有 |
| 默认结算周期 | 是 | 月 / 季 / 年 |

> 多账套间允许内部往来调拨，自动生成往来凭证。

## 12.7.4 预算管理

科室年度耗材预算控制：

| 字段 | 必填 | 说明 |
|------|------|------|
| 预算编号 | 自动 | YS + YYYY + 序号 |
| 预算年度 | 是 | - |
| 科室 | 是 | - |
| 预算类型 | 是 | 总额预算 / 品类预算 / 月度预算 |
| 预算金额 | 是 | - |
| 已使用金额 | 自动 | 实时统计消耗 |
| 已锁定金额 | 自动 | 已下单未到货 |
| 可用金额 | 自动 | 预算 - 已使用 - 已锁定 |
| 调整记录 | - | 中途追加 / 削减 |

**预警阈值：**
- 使用率 70% → 提醒科室主任
- 使用率 90% → 强制审批通过运营总监
- 使用率 100% → 冻结申领，须院领导特批超支

**预算类型：**
- 普通耗材预算
- 高值耗材预算（独立）
- 试剂预算（独立）
- 设备耗材预算（独立）

## 12.7.5 成本中心 / 成本归集

| 成本中心维度 | 说明 |
|--------------|------|
| 按科室 | 默认维度 |
| 按医生 | 高值耗材按主刀医生归集 |
| 按手术类型 | 按手术编码归集（DRG / DIP 准备） |
| 按病种 | 按 ICD-10 编码归集 |
| 按项目 | 临床研究项目专项 |

| 字段 | 必填 | 说明 |
|------|------|------|
| 归集单号 | 自动 | GB + YYYYMMDD + 序号 |
| 归集维度 | 是 | 见上 |
| 归集周期 | 是 | 日 / 月 / 季 / 年 |
| 归集明细 | 自动 | 自动汇总消耗记录 |
| 分摊规则 | 是 | 直接归集 / 按系数分摊 / 按使用量分摊 |

**应用场景：**
- 科室成本核算
- 医生绩效考核
- DRG / DIP 病种成本测算
- 医保结算依据

## 12.7.6 保证金 / 备货金 / 质保金

| 类型 | 说明 | 占用方 |
|------|------|--------|
| 投标保证金 | 招标时供应商缴纳，未中标退还 | 院方收取 |
| 履约保证金 | 中标后履约保障 | 院方收取 |
| 备货金 | 供应商在医院寄售/常备库存的资金占用 | 院方占用供应商 |
| 质保金 | 合同款扣留作质量保障 | 院方扣留 |

| 字段 | 必填 | 说明 |
|------|------|------|
| 保证金单号 | 自动 | BZ + YYYYMMDD + 序号 |
| 保证金类型 | 是 | 见上 |
| 关联合同 / 招标 | 是 | - |
| 供应商 | 是 | - |
| 金额 | 是 | - |
| 缴纳 / 扣留时间 | 是 | - |
| 期限 | 是 | 保证期 |
| 退还条件 | 是 | 文本说明 |
| 状态 | - | 待缴纳 / 已缴纳 / 已扣留 / 已退还 / 已没收 |

## 12.7.7 月结 / 反结 / 结账锁定

| 操作 | 说明 |
|------|------|
| 月结 | 每月结束后由财务发起月结，锁定本月数据 |
| 结账锁定 | 月结后该期间数据不允许修改 |
| 反结 | 特殊情况下解锁（须财务总监 + 审计 双签）|
| 跨月调整 | 锁定后的调整自动落到当前期间 |

| 字段 | 必填 | 说明 |
|------|------|------|
| 月结单号 | 自动 | YJ + YYYYMM |
| 结账周期 | 是 | YYYY-MM |
| 结账账套 | 是 | - |
| 结账类型 | 是 | 普通月结 / 季结 / 年结 |
| 结账人 | 自动 | - |
| 反结记录 | - | 反结操作历史 |
| 状态 | - | 未结 / 已结 / 已锁定 / 已反结 |

## 12.7.8 DRG / DIP 病种付费

按病种付费要求耗材成本归集到病种：

| DRG 字段 | 说明 |
|----------|------|
| DRG 组号 | HIS 提供 |
| 病案号 | HIS 患者标识 |
| 病种成本 | SPD 侧归集耗材 / 试剂 / 设备使用成本，其他医疗成本由外部系统提供 |
| 病种支付标准 | 医保规定 |
| 成本盈亏 | 实际成本 - 支付标准 |

**SPD 端配合：**
- 自动按 DRG 组归集耗材消耗
- 病种成本超支预警
- 病种内耗材使用合规检查（避免过度使用）
- 月度 DRG 病种耗材成本报表

## 12.7.9 医保目录管理

| 字段 | 必填 | 说明 |
|------|------|------|
| 商品编码 | 是 | 关联商品目录 |
| 医保编码 | 是 | 国家 / 省级医保编码 |
| 医保类别 | 是 | 甲类（全报）/ 乙类（部分报）/ 丙类（自费）|
| 报销比例 | 是 | 按地区医保政策 |
| 自费比例 | 是 | 乙类专用 |
| 限价 | 是 | 医保限价 |
| 限额 | 否 | 单次 / 单年用量限额 |
| 限制使用条件 | 否 | 病种限制、年龄限制等 |
| 适用医保类型 | 是 | 城镇职工 / 城乡居民 / 离休 / 工伤 |
| 生效日期 | 是 | - |
| 失效日期 | 否 | - |

> 医保目录与商品目录、价格目录联动，HIS 计费时自动套用最新规则。

## 12.7.10 医保驳回处理

医保审核驳回（耗材使用不合规）的处理流程：

| 阶段 | 操作 |
|------|------|
| 1. 接收驳回 | 医保平台推送驳回明细 |
| 2. 自动识别 | 系统按 UDI / 批号 / 患者匹配驳回耗材 |
| 3. 责任分析 | 主管医生 / 科室 / 收费 / 耗材使用 |
| 4. 整改方案 | 调整使用 / 退费 / 补费 / 申诉 |
| 5. 重新提交 | 整改后重新申报 |
| 6. 闭环跟踪 | 跟踪重新审核结果 |

| 字段 | 必填 | 说明 |
|------|------|------|
| 驳回单号 | 自动 | YB + 医保平台单号 |
| 驳回原因 | 是 | 不合理使用 / 超限额 / 超限价 / 资质不符 等 |
| 驳回金额 | 是 | - |
| 涉及患者 | 是 | - |
| 责任部门 | 是 | - |
| 处理方案 | 是 | - |
| 处理结果 | - | 已申诉成功 / 已退费 / 已补费 / 已闭环 |
