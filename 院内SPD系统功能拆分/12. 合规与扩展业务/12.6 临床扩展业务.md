# 12.6 临床扩展业务

> 所属模块：12. 合规与扩展业务
> 来源：院内SPD系统产品需求文档.md

## 12.6.1 功能概述

补全申领模板、紧急申领、跨科室借用、病区流转、患者押金、CSSD 对接、植入物专项档案等临床端节点，与 5.3 科室申领、8.6 科室业务、8.8 手术临床形成完整链路。

## 12.6.2 功能架构

```
临床扩展业务
├── 申领模板 / 套餐
├── 紧急申领绿色通道
├── 跨科室借用
├── 病区流转管理（科室二级库 → 病区 → 床头柜）
├── 患者押金管理
├── CSSD 消毒供应中心对接
└── 植入物专项档案
```

## 12.6.3 申领模板 / 套餐

科室常用申领套餐，一键带出明细：

| 字段 | 必填 | 说明 |
|------|------|------|
| 模板编号 | 自动 | MB + YYYYMMDD + 序号 |
| 模板名称 | 是 | 如"ICU 日常套餐"、"手术室基础包" |
| 适用科室 | 是 | 多选 |
| 模板类型 | 是 | 周常套餐 / 月常套餐 / 紧急套餐 / 项目套餐 |
| 模板明细 | 是 | 商品、规格、默认数量 |
| 周期 | 否 | 周 / 月 / 季 |
| 自动触发 | 否 | 是否到期自动生成申领 |
| 状态 | - | 启用 / 停用 |

> 申领单创建时支持"引用模板"，自动展开为多行明细，可调整数量。

## 12.6.4 紧急申领绿色通道

| 场景 | 说明 |
|------|------|
| 急救场景 | 如心梗、脑卒中等抢救物资 |
| 突发公共卫生事件 | 大规模急需 |
| 手术中临时缺货 | 手术中追加 |

| 字段 | 必填 | 说明 |
|------|------|------|
| 申领单号 | 自动 | JJ + YYYYMMDD + 序号 |
| 紧急级别 | 是 | 一级（生命危急）/ 二级（病情紧急）/ 三级（业务紧急） |
| 患者信息 | 是 | 姓名 / 住院号 / 病情简述 |
| 申领明细 | 是 | 商品、数量 |
| 主管医生 | 是 | 必填 |
| 状态 | - | 已发起 / 处理中 / 已发出 / 已签收 |

**响应时限：**
- 一级 → 5 分钟内出库 + 30 分钟内送达
- 二级 → 30 分钟内出库 + 1 小时内送达
- 三级 → 2 小时内出库 + 4 小时内送达

> 紧急申领可"先发后审"，系统自动通知科室主任 + 中心库主任 + 运营管理员，事后 24 小时内补审批。

## 12.6.5 跨科室借用

A 科室向 B 科室借用耗材（区别于 12.4.7 库房间借货）：

| 字段 | 必填 | 说明 |
|------|------|------|
| 借用单号 | 自动 | KS + YYYYMMDD + 序号 |
| 借出科室 | 是 | - |
| 借入科室 | 是 | - |
| 借用类型 | 是 | 应急 / 计划内 / 错领纠正 |
| 借用明细 | 是 | 商品、批号、数量、UDI |
| 借期 | 是 | 默认 7 天，紧急时 24 小时 |
| 还货方式 | 是 | 同品规归还 / 由中心库补发 |
| 状态 | - | 已发起 / 已确认 / 已交付 / 已归还 / 已折现 |

**审批：** 借出科室主任同意 → 借入科室主任同意 → 自动生成两科室间的临时调拨。

## 12.6.6 病区流转管理

科室二级库 → 病区 / 楼层 → 床头柜的多级流转：

| 流转层级 | 库存可见性 | 备注 |
|----------|------------|------|
| 科室二级库 | 库管员 / 科室主任 | 总账 |
| 病区分库 | 病区护士长 | 按病区拆分 |
| 床头柜 | 责任护士 | 按床位定数包 |

| 字段 | 必填 | 说明 |
|------|------|------|
| 流转单号 | 自动 | LZ + YYYYMMDD + 序号 |
| 流转方向 | 是 | 二级库 → 病区 / 病区 → 床头柜 |
| 流转明细 | 是 | 商品、批号、数量 |
| 责任人 | 是 | 接收人 |
| 床头柜定数包 | 否 | 床位号、定数包码 |

> 床头柜定数包扫码使用即消耗（实领实消模式），与 8.6.3 科室消耗联动。

## 12.6.7 患者押金管理

针对高值耗材（如心脏支架、人工关节）使用前的押金管理：

| 字段 | 必填 | 说明 |
|------|------|------|
| 押金单号 | 自动 | YJ + YYYYMMDD + 序号 |
| 患者信息 | 是 | 姓名、住院号 |
| 关联耗材 | 是 | 商品、UDI、单价 |
| 押金金额 | 是 | 默认 = 耗材定价 × 押金比例（如 50%） |
| 缴纳方式 | 是 | 现金 / 银行卡 / HIS 划账 |
| 缴纳时间 | 是 | - |
| 状态 | - | 已缴纳 / 已使用冲销 / 已退还 / 已没收 |

**冲销规则：**
- 耗材成功植入 → 押金自动转为耗材货款
- 取消手术未使用 → 押金全额退还
- 损坏丢失 → 没收押金，开正式收据

## 12.6.8 CSSD 消毒供应中心对接

复用器械（含植入器械、手术器械包）的消毒回收周转：

| 业务对象 | 说明 |
|----------|------|
| 复用器械 | 手术器械包、骨科钢板器械、内镜等 |
| CSSD 流转 | 使用 → 回收 → 清洗 → 消毒灭菌 → 包装 → 发放 → 使用 |

| 字段 | 必填 | 说明 |
|------|------|------|
| CSSD 单号 | 自动 | CS + YYYYMMDD + 序号 |
| 器械包编号 | 是 | 唯一码 |
| 器械明细 | 是 | 含件数清点 |
| 流转环节 | 是 | 回收 / 清洗 / 消毒 / 包装 / 发放 |
| 操作人 | 是 | 各环节责任人 |
| 灭菌方式 | 是 | 高温高压 / 环氧乙烷 / 等离子 |
| 灭菌指标 | 是 | 物理 / 化学 / 生物三重指标 |
| 灭菌结果 | 是 | 合格 / 不合格 |
| 失效日期 | 自动 | 按灭菌方式计算 |

**对接接口：** SPD ↔ CSSD 系统通过标准接口同步器械流转 + 失效预警，确保器械安全可追溯。

## 12.6.9 植入物专项档案

永久植入耗材（如心脏起搏器、人工关节、骨科钢板）的终身追溯：

| 字段 | 必填 | 说明 |
|------|------|------|
| 档案编号 | 自动 | ZR + 患者ID + UDI |
| 患者信息 | 是 | 姓名、住院号、身份证、联系方式 |
| 植入耗材 | 是 | 商品、UDI、批号、生产厂家、注册证 |
| 植入手术 | 是 | 关联手术单 |
| 植入医生 | 是 | 主刀 + 助手 |
| 植入部位 | 是 | 详细部位描述 |
| 植入日期 | 是 | - |
| 预期使用年限 | 是 | 厂家标定 |
| 随访计划 | 自动 | 1 月 / 3 月 / 6 月 / 1 年 / 每年 |
| 随访记录 | - | 随访结果（可通过 HIS 同步） |
| 召回响应 | 自动 | 关联 12.5.3 召回，命中自动通知 |
| 取出 / 失效 | 否 | 取出日期、原因 |

**留档期限：** 永久（≥ 患者生命周期）。

**患者出院后：** 自动生成患者卡（PDF + 电子卡），含 UDI、保修期、随访建议。
