# 3.3 角色权限管理

> 所属模块：3. 基础管理模块
> 来源：院内SPD系统产品需求文档.md

## 3.3.1 功能概述

角色管理是系统RBAC权限模型的核心，用于定义系统中的角色，并为每个角色分配菜单权限和数据权限，实现基于角色的访问控制。

## 3.3.2 数据范围选项

| 选项值 | 显示文字 | 说明 |
|--------|----------|------|
| 1 | 全部数据 | 可查看所有数据 |
| 2 | 本部门数据 | 仅查看所属部门数据 |
| 3 | 本部门及子部门 | 查看本部门及下属部门数据 |
| 4 | 仅本人数据 | 仅查看自己创建的数据 |
| 5 | 自定义 | 指定特定部门 |

## 3.3.3 核心功能

| 功能 | 说明 |
|------|------|
| 角色列表查询 | 支持按角色名称、角色编码、状态筛选 |
| 新增角色 | 设置角色名称、编码、数据范围、状态 |
| 编辑角色 | 修改角色信息，角色编码不可修改 |
| 删除角色 | 不能删除系统预置角色和已被用户关联的角色 |
| 分配权限 | 为角色分配菜单权限和按钮权限（权限树） |
| 数据权限 | 设置角色的数据查看范围 |

## 3.3.4 预置角色

| 角色名称 | 角色编码 | 数据范围 | 功能权限 | 说明 |
|----------|----------|----------|----------|------|
| 系统管理员 | admin | 全部数据 | 所有菜单+按钮 | 系统超级管理员 |
| 运营管理员 | operator | 本部门及子部门 | 商品目录、供应商、库存、采购、报表查看 | 日常运营管理 |
| 采购人员 | purchaser | 本部门数据 | 采购管理、供应商管理、采购计划、订单管理 | 采购计划、订单管理 |
| 库管人员 | warehouse | 本部门数据 | 库存管理、入库、出库、盘点、UDI追溯、冷链监控 | 入库、出库、盘点 |
| 科室人员 | dept_user | 仅本人数据 | 科室申领、高值耗材使用登记、收货确认 | 科室申领、使用登记 |
| 财务人员 | finance | 本部门数据 | 结算对账、发票管理、付款审批、报表中心 | 结算对账、报表查看 |
| 质控人员 | qc | 全部数据 | UDI追溯、冷链监控、报表中心、质量监控 | 质量监控、追溯审计 |
| 医生/护士 | doctor | 仅本人数据 | 高值耗材使用、患者关联 | 高值耗材使用 |
| 院领导 | leader | 全部数据 | 报表中心、运营总览 | 运营总览、决策分析 |
| 审计人员 | auditor | 全部数据 | 操作日志、登录日志、数据查询、报表查看（只读） | 数据查询、报表查看 |
| 供应商 | supplier | 仅本人数据 | 商品申请、订单查看、配送管理、对账查询 | 外部供应商 |
| 审批人员 | approver | 本部门及子部门 | 待办审批、审批记录、流程查看 | 各业务审批节点 |
