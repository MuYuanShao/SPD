# 12.5 召回与质量闭环

> 所属模块：12. 合规与扩展业务
> 来源：院内SPD系统产品需求文档.md

## 当前实现基线（2026-07-13）

**实现状态：部分实现。** 召回事件能够按库房、商品和数量发起隔离，库存移动服务以 FIFO 锁定余额，将可用量转入隔离量并记录不可变事件。

- [x] 隔离前校验正数量和库存充足性。
- [x] 隔离后可用库存不为负，隔离数量同步增加。
- [x] 事件保留召回来源业务、批次、变动量和变动后数量。
- [x] 召回页面不展示库存事件快照模块。
- [ ] 供应商召回通知导入、命中患者范围、处置复核、退供应商/销毁和监管上报仍需闭环建设。

## 12.5.1 功能概述

补全召回完整闭环（厂家通知 → 库存筛查 → 已用追踪 → 患者通知 → 处置）、不良事件后续追踪、批号偏差处理、临床应用风险评估等质量合规节点。

## 12.5.2 功能架构

```
召回与质量闭环
├── 召回管理（完整闭环）
│   ├── 召回通知接收
│   ├── 库存全院筛查
│   ├── 已使用追踪
│   ├── 患者通知
│   └── 处置闭环
├── 不良事件后续追踪
├── 批号偏差处理
├── 临床应用风险评估
└── 法规符合性 Checklist
```

## 12.5.3 召回管理（完整闭环）

| 阶段 | 操作 |
|------|------|
| 1. 召回通知接收 | 厂家通过供应商门户提交召回函 / 国家不良事件中心推送 / 手工录入 |
| 2. 自动筛查 | 系统按"商品 + 批号 + UDI"全集团库存筛查（含中心库 / 二级库 / 隔离库 / 借出冻结） |
| 3. 库存隔离 | 命中库存自动转入"召回隔离库"，禁止任何出库 |
| 4. 已使用追踪 | 通过 6.1 UDI 追溯链，定位已发出 / 已消耗 / 已植入患者 |
| 5. 患者通知 | 高值植入耗材：自动列出涉事患者清单，推送至 HIS 患者档案 + 主管医生 + 医务部 |
| 6. 处置 | 退供应商 / 销毁 / 替换重发 |
| 7. 闭环报告 | 生成召回总结报告，上报国家不良事件监测中心 |

| 字段 | 必填 | 说明 |
|------|------|------|
| 召回单号 | 自动 | ZH + YYYYMMDD + 序号 |
| 召回类型 | 是 | 主动召回 / 被动召回（监管要求）|
| 召回级别 | 是 | 一级（致死/重伤）/ 二级（暂时性损害）/ 三级（不太可能造成损害） |
| 召回原因 | 是 | 文本 + 召回函附件 |
| 涉事商品 / 批号 / UDI | 是 | 多行 |
| 全院命中库存 | 自动 | 自动汇总 |
| 已发出未使用 | 自动 | 二级库 / 借出冻结 |
| 已使用已植入 | 自动 | UDI 追溯命中患者数 |
| 处置方式 | 是 | 退供应商 / 销毁 / 替换重发 |
| 上报状态 | 是 | 已上报国家中心 / 待上报 / 院内闭环 |
| 状态 | - | 草稿 / 处理中 / 已闭环 / 已上报 |

**响应时限：**
- 一级召回：4 小时内库存隔离 + 24 小时内患者通知
- 二级召回：24 小时内库存隔离 + 72 小时内患者通知
- 三级召回：72 小时内库存隔离 + 7 天内患者通知

## 12.5.4 不良事件后续追踪闭环

补全 8.6.6 的后续节点：

| 阶段 | 说明 |
|------|------|
| 1. 上报后跟踪 | 国家平台反馈编号、处理状态自动同步 |
| 2. 厂家整改通知 | 厂家提交整改报告（通过供应商门户）|
| 3. 院内复评 | 质控部门评估整改有效性 |
| 4. 是否触发召回 | 严重事件升级为 12.5.3 召回 |
| 5. 患者随访 | 高值耗材植入患者强制随访 |
| 6. 闭环归档 | 永久留档 ≥ 10 年 |

| 字段 | 必填 | 说明 |
|------|------|------|
| 跟踪单号 | 自动 | GZ + 不良事件编号 |
| 国家平台反馈号 | 否 | 上报后回填 |
| 厂家整改报告 | 是 | 上传 PDF |
| 院内复评结果 | 是 | 已闭环 / 不接受 / 需进一步整改 |
| 是否升级召回 | 是 | 是 / 否 |
| 随访记录 | 否 | 患者随访明细 |

## 12.5.5 批号偏差处理

| 场景 | 处理 |
|------|------|
| 不同批号合并使用 | 默认禁止；如必须合并须批号偏差申请，运营 + 质控双签 |
| 批号信息异常（错印 / 模糊） | 入库强制扫码识别失败 → 转隔离 → 厂家确认后释放 |
| 批号变更（厂家通知） | 旧批号库存自动标记，新批号入库 |

| 字段 | 必填 | 说明 |
|------|------|------|
| 偏差单号 | 自动 | PC + YYYYMMDD + 序号 |
| 商品 + 批号 | 是 | - |
| 偏差类型 | 是 | 见上 |
| 偏差描述 | 是 | 文本 |
| 处理建议 | 是 | 隔离 / 退供应商 / 释放使用 |
| 审批 | 是 | 库管主任 + 质控员 |

## 12.5.6 临床应用风险评估

针对高风险耗材（高值植入物 / 进口耗材 / 新准入耗材）的入院前评估：

| 评估维度 | 权重 | 内容 |
|----------|------|------|
| 临床有效性 | 30% | 文献证据、临床试验数据 |
| 安全性 | 30% | 不良事件历史、不良反应率 |
| 经济性 | 20% | 性价比 / 医保覆盖 |
| 替代性 | 10% | 是否有同类产品 |
| 合规性 | 10% | 注册证、生产许可、监管历史 |

| 字段 | 必填 | 说明 |
|------|------|------|
| 评估单号 | 自动 | PG + YYYYMMDD + 序号 |
| 商品 | 是 | - |
| 申请科室 | 是 | - |
| 评估专家 | 是 | 临床 + 药学 + 设备 + 院感 ≥ 5 人 |
| 评估结果 | 是 | 通过准入 / 限制使用 / 不予准入 |
| 限制条件 | 否 | 仅特定科室 / 仅特定病种 / 用量上限 |
| 复评周期 | 是 | 一年 / 三年 / 永久 |

## 12.5.7 法规符合性 Checklist

| 法规 | 适用 | 检查项 |
|------|------|--------|
| 医疗器械监督管理条例 | 全部耗材 | 注册证、经营许可、生产许可 |
| UDI 实施细则 | 国家三级 / 二级 UDI 强制品种 | UDI 完整性、唯一性、可追溯性 |
| 医疗器械经营质量管理规范 / GSP 类质量管理要求 | 试剂 / 高值耗材 / 冷链耗材 | 储存条件、流通规范 |
| 医疗器械不良事件监测和再评价管理办法 | 全部耗材 | 上报时限、记录留档 |
| 医疗器械召回管理办法 | 全部耗材 | 召回响应时限、闭环要求 |
| 医疗保障基金使用监督管理条例 | 医保耗材 | 医保规则符合性、计费合规 |
| 医院感染管理办法 | 一次性 / 介入耗材 | 院感控制流程 |
| 个人信息保护法 / HIPAA 类要求 | 患者数据 | 脱敏、最小必要、留痕 |

> 系统在每个相关业务节点自动校验对应法规要求，未通过强制阻断 + 提示。
