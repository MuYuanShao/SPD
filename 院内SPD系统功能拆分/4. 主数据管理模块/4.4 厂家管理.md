# 4.4 厂家管理

> 所属模块：4. 主数据管理模块
> 来源：院内SPD系统产品需求文档.md

## 4.4.1 功能概述

厂家（生产商/制造商）是医疗物资的源头，医院需要建立完整的厂家档案，实现厂家信息的标准化管理。

## 4.4.2 核心功能

| 功能 | 说明 |
|------|------|
| 厂家列表 | 支持按编码、名称、类型、状态、资质状态筛选 |
| 新增厂家 | 填写厂家基本信息、生产信息、联系人信息 |
| 编辑厂家 | 修改厂家信息 |
| 厂家详情 | 查看基础信息、资质信息、关联商品、关联供应商、操作记录 |
| 资质管理 | 管理厂家资质附件，支持到期预警 |
| 关联商品 | 查看该厂家生产的商品列表 |
| 关联供应商 | 查看代理该厂家的供应商列表 |

## 4.4.3 厂家表单字段

| 字段 | 必填 | 校验规则 |
|------|------|----------|
| 厂家名称 | 是 | 2-100字符，不可重复 |
| 统一社会信用代码 | 是 | 18位，校验规则 |
| 厂家类型 | 是 | 生产商/品牌商/代工厂 |
| 注册地区 | 是 | 省市区三级选择 |
| 联系人姓名 | 是 | 2-50字符 |
| 联系电话 | 是 | 手机号或固话格式 |
