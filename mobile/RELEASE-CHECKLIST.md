# 安卓发布与互通验收清单

## 服务器

- [ ] 使用医院内网 DNS/IP，API 前缀为 `/api`。
- [ ] 测试环境与正式环境使用不同服务器标识和数据库，APP 可在登录页修改环境及服务器地址。
- [ ] 切换服务器前已退出账号；存在未解决队列时阻止切换或要求处理完成。
- [ ] HTTPS 证书由安卓系统默认信任的公开 CA 签发，使用正式 DNS 域名；不要求设备额外安装 CA。
- [ ] 配置 `SPD_MOBILE_ENABLED`、`SPD_MOBILE_SERVER_ID`、`SPD_MOBILE_REVIEW_SECRET`。
- [ ] 备份 MySQL，执行 Flyway `V80__mobile_operation_receipt`。
- [ ] 为移动账号配置 `picking-delivery:write` 和对应科室/库房范围。
- [ ] `/api/health`、登录、移动上下文和回执查询可用。

## Android

- [ ] Android 9+ 真机安装 APK（minSdk 28），确认系统 WebView 66+；正式环境禁止明文 HTTP，服务器证书链和域名校验通过。
- [ ] 相机权限拒绝后，键盘扫码和手工输入仍可用。
- [ ] PDA 扫描以 Enter 结束，数量输入不会混入扫码缓冲。
- [ ] App 重启后本地未解决记录仍可见。
- [ ] APK 升级后队列 schema 可迁移，签名一致。

## 在线、弱网和离线

- [ ] 在线登录、上下文选择、任务查询和签收成功。
- [ ] 弱网超时进入“结果确认中”，原 operationId 查询结果。
- [ ] 断网扫码只进入本地暂存，不改变服务器库存。
- [ ] 恢复网络后先校验，再由用户确认提交。
- [ ] 同操作号重复提交只产生一次业务写入。
- [ ] 同操作号修改载荷返回冲突。

## 与电脑端并发

- [ ] 电脑端先签收，手机提交必须冲突，库存只变化一次。
- [ ] 手机预校验后电脑端修改原单，手机最终提交必须重新校验失败。
- [ ] 两台设备扫描同一唯一码，仅一台成功。
- [ ] 一台设备切换账号后，原账号队列不能被新账号查询或提交。
- [ ] 验收数据使用隔离 MySQL，不使用正式库存。

## 证据

保存 APK SHA-256、设备型号/Android 版本、服务器版本、测试账号、操作号、业务单号、库存流水号和测试时间，作为发布记录。
