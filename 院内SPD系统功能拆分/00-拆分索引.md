## 当前产品边界

- 库存管理仅展示库存余额；库存交易历史属于独立功能，不混入库存余额查询。
- 不新增或恢复“库存事件快照”业务模块，也不在补货、消耗、收费耗材、冷链或召回页面展示该模块。
- 高值耗材的科室领用不代表已经计费。SPD 仅在收到 HIS、手麻或手术系统计费数据后扣减库存并写入追溯。
- 科室申领入口首先展示历史申领单摘要；新建时只能从当前科室目录选择商品。
- UDI/唯一码追溯同时覆盖高值耗材和低值定数包。

## 2026-07-13 可验证基线

- 后端：Spring Boot 3 / Java 17 / MySQL / Flyway，业务响应使用统一 `ApiResponse`，分页使用 `rows/total/page/size/summary`。
- 前端：Vue 3 / Vite / Element Plus，业务页面通过真实 `/api` 客户端读取数据。
- 库存：收货、FIFO 扣减、调拨、盘点调整和召回隔离统一维护非负余额并写不可变库存事件。
- 追溯：UDI 详情、列表、时间线、高值耗材与低值定数包范围已经落库；不存在的码返回明确错误。
- 高值收费：外部计费号幂等，双码一致性校验，计费后扣减库存，并使用 `trace_code_id` 关联收费与追溯记录。
- 自动化证据：后端全量测试、真实 MySQL 双线程计费回调测试、前端生产构建及收费明细 Playwright 冒烟测试。
