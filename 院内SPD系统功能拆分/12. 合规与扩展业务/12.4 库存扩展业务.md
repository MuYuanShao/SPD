# 12.4 库存扩展业务

> 所属模块：12. 合规与扩展业务
> 来源：院内SPD系统产品需求文档.md

## 12.4.1 功能概述

补全库房间调拨、货位移库、报损报废、盘亏盘盈调账、借货、临时入库、FIFO/FEFO 强制规则等关键库存动作，覆盖第 5.2 库存管理之外的全部库存调整场景。

## 12.4.2 功能架构

```
库存扩展业务
├── 库房间调拨（同院区）
├── 货位移库 / 移位
├── 报损报废单
├── 盘亏盘盈调账单
├── 借货管理（借出 / 借入）
├── 临时入库
├── 库存调账单
└── FIFO / FEFO 强制规则
```

## 12.4.3 库房间调拨

同院区不同库房间的物资调拨（中心库 ↔ 二级库 / 二级库 ↔ 二级库）。

| 字段 | 必填 | 说明 |
|------|------|------|
| 调拨单号 | 自动 | KB + YYYYMMDD + 序号 |
| 调出库房 | 是 | - |
| 调入库房 | 是 | - |
| 调拨类型 | 是 | 库存均衡 / 应急借调 / 业务转移 / 错发纠正 |
| 调拨明细 | 是 | 商品、批号、数量、UDI |
| 调拨理由 | 是 | 文本 |
| 价格处理 | 自动 | 同院区不计价（成本价同步） |
| 状态 | - | 草稿 / 待出库 / 在途 / 已收货 / 已确认 |

**审批：** 5 万以下库管主任审批；5–20 万运营主任 + 财务；20 万以上院领导。

## 12.4.4 货位移库 / 移位

同库房内物资从一个货位移动到另一个货位，不涉及科室 / 库房变化。

| 字段 | 必填 | 说明 |
|------|------|------|
| 移位单号 | 自动 | YW + YYYYMMDD + 序号 |
| 库房 | 是 | - |
| 原货位 | 是 | - |
| 目标货位 | 是 | - |
| 移位明细 | 是 | 商品、批号、数量 |
| 移位原因 | 是 | 库位优化 / 货位空间 / 临近过期前置 |
| 操作人 | 是 | - |

> 移位不影响库存数量，仅更新货位字段，但纳入审计日志。PDA 端支持扫"原货位"→ 扫"商品"→ 扫"目标货位"三步完成。

## 12.4.5 报损报废单

针对实物损耗（破损 / 过期 / 污染 / 霉变 / 召回销毁等），需独立审批流：

| 字段 | 必填 | 说明 |
|------|------|------|
| 报损单号 | 自动 | BS + YYYYMMDD + 序号 |
| 报损库房 | 是 | - |
| 报损类型 | 是 | 破损 / 过期 / 污染 / 召回销毁 / 损耗 / 检验失败 |
| 报损明细 | 是 | 商品、批号、UDI、数量、原值 |
| 责任认定 | 是 | 厂家责任 / 物流责任 / 院方责任 / 不可抗力 |
| 处置方式 | 是 | 销毁 / 退供应商 / 报废回收 |
| 现场照片 | 是 | 必传 ≥ 3 张 |
| 涉及金额 | 自动 | Σ(数量 × 成本价) |

**审批分级：**
- ≤ 1 千 → 库管主任
- 1 千–1 万 → 运营主任 + 财务
- > 1 万 → 院领导 + 财务总监 + 质控主任

**后置动作：** 自动生成红字凭证 → 减少库存 → 财务核销 → 实物销毁需视频留档。

## 12.4.6 盘亏盘盈调账单

| 触发 | 说明 |
|------|------|
| 盘点差异 | 5.2 库存盘点 / 8.5.9 新盘点单 完成后差异行 |
| 长期未匹配 | 系统库存与实物长期不一致 |

| 字段 | 必填 | 说明 |
|------|------|------|
| 调账单号 | 自动 | TZ + YYYYMMDD + 序号 |
| 关联盘点单 | 是 | - |
| 差异类型 | 是 | 盘亏 / 盘盈 |
| 差异明细 | 是 | 商品、批号、账面 / 实盘 / 差异 |
| 差异原因 | 是 | 计量误差 / 错收发 / 失窃 / 错领 / 其他 |
| 责任人 | 是 | 必填 |
| 处理建议 | 是 | 直接调账 / 追责赔偿 / 报警立案 |
| 调账金额 | 自动 | Σ(差异数量 × 成本价) |

**审批分级：**
- 单笔差异 ≤ 5 千 → 运营主任 + 财务
- 5 千–5 万 → 运营总监 + 财务总监 + 审计
- > 5 万 → 院领导 + 法务 + 审计 + 必要时报警

## 12.4.7 借货管理

应急场景下不通过正式申领 / 调拨流程，先借出后补单。

| 借货类型 | 说明 |
|----------|------|
| 院内借出 | 本院某库房应急借给其他库房 |
| 兄弟医院借出 | 借给兄弟单位（罕见情况） |
| 兄弟医院借入 | 从兄弟单位借入 |

| 字段 | 必填 | 说明 |
|------|------|------|
| 借货单号 | 自动 | JH + YYYYMMDD + 序号 |
| 借货类型 | 是 | 见上 |
| 借出 / 借入方 | 是 | - |
| 借货明细 | 是 | 商品、批号、数量、UDI |
| 借期 | 是 | 必填，逾期触发预警 |
| 还货方式 | 是 | 同品规归还 / 等价折现 |
| 状态 | - | 已借出 / 已部分归还 / 已归还 / 已折现 / 逾期 |

> 院内借出的库存数量不直接扣减，而进入"借出冻结"状态，归还时解冻；兄弟医院借入须经法务备案。

## 12.4.8 临时入库

无单到货应急（如供应商先送货后补单、紧急配送、捐赠物资）：

| 字段 | 必填 | 说明 |
|------|------|------|
| 临时入库单号 | 自动 | LR + YYYYMMDD + 序号 |
| 入库类型 | 是 | 无单应急 / 捐赠 / 援助物资 / 退还借货 |
| 入库库房 | 是 | - |
| 入库明细 | 是 | 商品、批号、数量 |
| 来源说明 | 是 | 必填 |
| 限期补单 | 是 | 默认 7 天内必须补正式入库单 |
| 库存状态 | 自动 | 隔离库存（不可出库），补单后转可用 |

**强制约束：** 限期未补单的临时入库自动通知运营总监 + 库管主任，超 30 天自动转报损。

## 12.4.9 FIFO / FEFO 强制规则

| 规则 | 说明 |
|------|------|
| FIFO（先进先出） | 默认拣货顺序按入库时间升序 |
| FEFO（近效期先出） | 高值耗材、试剂、冷链耗材必须 FEFO |
| 强制规则 | 拣配作业（8.4.3）/ 出库 / 申领出库均按规则自动选批 |
| 例外审批 | 跳过近效期批号需 PDA 上提示 + 库管主任审批 |
| 异常监控 | 系统记录所有 FIFO/FEFO 例外，月度报表 |

| 商品类别 | 默认规则 | 可调整 |
|----------|----------|--------|
| 普通耗材 | FIFO | 可改 FEFO |
| 高值耗材 | FEFO | 不可改 |
| 试剂 | FEFO | 不可改 |
| 冷链耗材 | FEFO | 不可改 |
| 设备耗材 | FIFO | 可改 |
