# 8.6 科室业务管理

> 所属模块：8. 院内SPD业务扩展模块
> 来源：院内SPD系统产品需求文档.md

## 8.6.1 功能概述

补充科室端 SPD 业务节点：科室收货（已在 5.3）之后的消耗、日清确认、使用反馈、不良事件上报、消耗报表汇总。

## 8.6.2 功能架构

```
科室业务管理
├── 科室收货（详见 5.3.2）
├── 科室消耗
├── 科室日清确认
├── 耗材使用意见反馈
├── 不良事件上报
├── 科室消耗报表
└── 科室消耗汇总
```

## 8.6.3 科室消耗

科室二级库消耗扣减节点（区别于先前申领出库）：

| 消耗模式 | 说明 |
|----------|------|
| 实领实消 | 申领即消耗，扣减二级库库存 |
| 实领实结 | 申领消耗按月统一结算 |
| 实销实结 | 实际使用扫码后才扣减并计费（先收费后消耗手术单专用） |
| 定数包消耗 | 拆开使用即整包消耗 |

| 字段 | 说明 |
|------|------|
| 消耗单号 | XH + YYYYMMDD + 序号 |
| 消耗科室 | 自动带入 |
| 消耗类型 | 申领消耗 / 手术消耗 / 损耗 / 转赠 |
| 关联单据 | 申领单 / 手术单 |
| 患者信息 | 高值耗材必填 |
| 消耗明细 | 商品、批号、数量、消耗人、消耗时间 |
| 状态 | 待确认 / 已确认 / 已结算 / 已反消耗 |

## 8.6.4 科室日清确认

每日工作结束时科室对当日所有消耗、收货、退库、剩余库存进行盘清确认：

| 操作 | 说明 |
|------|------|
| 拉取当日数据 | 系统自动汇总当日入/出/消耗/盘点 |
| 现场盘点 | PDA 扫描定数包 / 散货数量 |
| 差异核对 | 与系统理论库存比对 |
| 异常上报 | 差异行强制说明原因 |
| 日清提交 | 科室主任电子签字 |
| 日清状态 | 未日清 / 已日清 / 异常 |

> 未日清的科室次日不允许新增申领，强制闭环。

## 8.6.5 耗材使用意见反馈

| 字段 | 必填 | 说明 |
|------|------|------|
| 反馈编号 | 自动 | YJ + YYYYMMDD + 序号 |
| 反馈科室 / 人员 | 是 | - |
| 关联耗材 | 是 | 商品 / 批号 / 厂家 |
| 反馈类型 | 是 | 质量问题 / 使用体验 / 包装问题 / 改进建议 |
| 严重等级 | 是 | 一般 / 重要 / 紧急 |
| 描述 | 是 | 文本 + 图片附件 |
| 处理状态 | - | 待处理 / 已转厂家 / 已回复 / 已关闭 |

> 严重等级"紧急"自动同步至质控人员、运营管理员。

## 8.6.6 不良事件上报

满足国家《医疗器械不良事件监测和再评价管理办法》要求：

| 字段 | 必填 | 说明 |
|------|------|------|
| 事件编号 | 自动 | BL + YYYYMMDD + 序号 |
| 患者信息 | 是 | 姓名、住院号、身份证（脱敏） |
| 涉事耗材 | 是 | 商品、UDI、批号、注册证号、生产厂家、供应商 |
| 事件类型 | 是 | 死亡 / 严重伤害 / 可能严重伤害 |
| 发生时间 | 是 | - |
| 事件描述 | 是 | 详细经过 |
| 已采取措施 | 是 | - |
| 上报途径 | 是 | 院内 / 已上报国家不良事件监测中心 |
| 附件 | 否 | 病历、照片 |

**上报流程：**
```
[科室上报] → [科室主任审核] → [医务部审核] → [质控人员审核]
    → [上报国家监测平台 / 内部留档] → [跟踪处理]
```

## 8.6.7 科室消耗报表

| 报表 | 说明 |
|------|------|
| 科室日消耗 | 当日各品种消耗量与金额 |
| 科室月消耗 | 月度消耗趋势 |
| 科室耗材排名 | TopN 高耗品种 |
| 患者人均消耗 | 高值耗材专用 |
| 同比 / 环比 | 与上期对比 |

## 8.6.8 科室消耗汇总

跨科室、跨时间维度的消耗汇总：

| 维度 | 输出 |
|------|------|
| 全院按科室 | 各科室消耗金额、占比 |
| 按耗材分类 | 各类耗材科室消耗分布 |
| 按医生 | 医生使用耗材排行（高值） |
| 按手术类型 | 不同手术耗材成本 |
