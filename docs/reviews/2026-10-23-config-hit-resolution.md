# 按配置键隔离的命中说明

本次仅修复配置记录解释及重复身份写入提示，不接入结算策略引擎，不改动已有配置记录。

## 接口与匹配口径

- GET /api/config-hit-explanation 现在必须提供 configKey；configType 保持默认 workflow。缺键返回中文业务错误，不再跨键选第一条。
- GET /api/config-hit-explanation/options?configType=workflow 返回当前类型下未删除记录的去重配置键及名称。停用或过期记录仍可选择，方便核对“未命中”；选项不返回配置值。
- 只匹配启用、已到生效时间且未过失效日期的同类型、同键记录；失效日期沿用原语义，包含当天。
- 范围优先级：用户1、模块2、库房3、科室4、院区5、医院6、租户7、系统专用范围8、默认范围9。
- 只将严格更粗范围的同键记录作为继承来源。无父配置时显示“无继承配置”，不再把第二条任意记录叫作上级。
- 同键任一级别出现多个有效候选时，明确返回 conflict=true；不判定最终配置或覆盖关系，候选保留，供人工核对。
- 新增/修改/启用前检查同身份生效冲突。现有 uk_config_scope_key 唯一约束继续作为并发保障；其限制包含停用/过期记录，重复身份应编辑原记录，数据库重复错误转换成可操作的中文提示。
- 响应新增 configKey、parentConfigId、parentSourceLevel、conflict、matchReason、executionNote；候选新增 conflict 和 matchReason。原 approvalStatus 字段保留兼容结构，但在页面标注为“匹配状态”，不冒充审批进度。

## 页面

增加配置项选择、配置键、继承来源和匹配原因。切换类型时重新加载键；切换键清除上次结果。按请求序列丢弃旧类型或旧键的慢响应；选项失败或为空时不能沿用旧键查询。

配置记录匹配与实际执行分别说明。已知工作台预警、MCP-UI配置显示对应使用范围；其他键目前没有消费者，明确标示未接入业务执行，不宣称通用JSON控制结算时点或审批进度。新增配置消费者时须同步核对该说明。
