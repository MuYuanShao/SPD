# 3.4 科室管理

> 所属模块：3. 基础管理模块
> 来源：院内SPD系统产品需求文档.md

## 3.4.1 功能概述

科室管理是系统组织架构的基础模块，用于维护医院的科室/部门层级结构。科室数据作为用户归属、数据权限、业务流转的基础维度。

## 3.4.2 页面布局

```
+----------------------------------------------------------+
|  科室管理                                                  |
+----------------------------------------------------------+
|  [新增科室] [展开全部] [折叠全部] [刷新]                    |
+----------------------------------------------------------+
|  [搜索区域]                                                |
|  科室名称: [________]  状态: [全部▼]  [查询] [重置]         |
+----------------------------------------------------------+
|  [树形表格]                                                |
|  科室名称      | 科室编码 | 负责人 | 电话      | 排序 | 状态 | 操作 |
+----------------------------------------------------------+
```

## 3.4.3 核心功能

| 功能 | 说明 |
|------|------|
| 科室树查询 | 树形展示科室层级，支持展开/折叠 |
| 新增科室 | 支持新增顶级科室和子科室 |
| 编辑科室 | 修改科室信息，支持变更上级科室 |
| 删除科室 | 有子节点或关联用户的科室不能删除 |
| 展开/折叠 | 一键展开或折叠所有节点 |

## 3.4.4 科室表单字段

| 字段 | 类型 | 必填 | 校验规则 |
|------|------|------|----------|
| 上级科室 | 级联选择 | 条件必填 | 新增子科室时自动填充 |
| 科室名称 | 输入框 | 是 | 2-50字符 |
| 科室编码 | 输入框 | 是 | 2-50字符，字母数字下划线，唯一 |
| 财务科室 | 输入框 | 否 | 2-50字符，关联财务核算体系 |
| 财务科室编码 | 输入框 | 否 | 2-50字符，字母数字下划线，唯一 |
| 科室地址 | 输入框 | 否 | 2-200字符 |
| 院区 | 下拉选择 | 否 | 东院区/西院区/南院区/北院区/主院区 |
| 负责人 | 输入框 | 否 | 2-20字符 |
| 联系电话 | 输入框 | 否 | 电话格式 |
| 排序 | 数字输入 | 否 | 0-999 |
| 状态 | 开关 | 是 | 启用/禁用 |
