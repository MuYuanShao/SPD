# 8.4 拣配出库与配送

> 所属模块：8. 院内SPD业务扩展模块
> 来源：院内SPD系统产品需求文档.md

## 当前实现基线（2026-07-13）

**实现状态：部分实现。** 已支持待拣申领、定数包标签选择、拣货确认、配送单和科室签收。

- 配送单与定数包标签建立显式绑定，列表可展示包数和标签号。
- 签收时记录目标科室库房，并通过库存移动服务完成来源库房到目标库房的库存调拨。
- 同一配送单状态更新使用条件更新，重复签收不能重复转移库存。
- [ ] PDA 离线拣配冲突、路线优化、交接签名和异常拒收仍需完整端到端验收。

## 8.4.1 功能概述

补充 SPD 院内"拣配 → 散货打包出库转补货 → RFID 附码 → 出库配送 → 库房出库明细汇总 → 补货单查询"完整链条。

## 8.4.2 功能架构

```
拣配出库与配送
├── 拣配作业
├── 出库配送
├── 申领单散货打包出库转补货节点
├── 预留低值出库 RFID 附码节点
├── 预留高值出库 RFID 附码节点
├── 对应库房出库
├── 库房出库明细
├── 库房出库汇总
└── 补货单查询
```

## 8.4.3 拣配作业（拣配）

| 字段 | 说明 |
|------|------|
| 拣配单号 | JP + YYYYMMDD + 序号 |
| 来源单据 | 申领单 / 请货单 / 补货单 |
| 拣配模式 | 单单拣 / 批量拣 / 波次拣 |
| 拣配明细 | 商品、应拣量、批号优先（FIFO/近效期）、推荐货位 |
| 拣配人 | 自动带入 |
| 状态 | 待拣 / 拣配中 / 已拣 / 待复核 |

**PDA 拣配流程：** 扫描拣配单 → 系统按最优路径推荐 → 扫描货位 → 扫描商品 → 录入实拣量 → 提交完成。

## 8.4.5 申领单散货打包出库转补货节点

申领单中的散货物品在出库时，若该项已使其引导货位散货低于安全量 → 自动生成"散货补货单"反向请求中心库补货：

```
[申领出库扫码] → [扫描散货标签] → [出库执行] → [校验散货货位库存]
    ↓ 低于阈值
[自动生成散货补货单（草稿）] → [中心库审核] → [散货收货上架]
```

> 该节点是 SPD 院内闭环关键：申领出库即触发补货，避免散货空架。

## 8.4.6 预留低值出库 RFID 附码节点

为后续"全院 RFID 化"预留入口（当前业务可关闭，仅占位）：

| 字段 | 说明 |
|------|------|
| 节点开关 | 系统配置项 `rfid.lowvalue.attach.enabled` |
| 触发时机 | 低值耗材出库前 |
| 操作 | 扫描产品码 → 关联 RFID 标签号 → 写入 RFID 数据库 |
| 用途 | 全院射频追溯（实时定位、自动盘点） |

## 8.4.7 预留高值出库 RFID 附码节点

| 字段 | 说明 |
|------|------|
| 节点开关 | `rfid.highvalue.attach.enabled` |
| 触发时机 | 高值耗材出库前（已含 UDI，再附 RFID 用于手术室自动识别） |
| 操作 | 扫描 UDI → 写入 RFID → UDI ↔ RFID 映射 |
| 用途 | 手术室自动盘存、丢失防护、术后自动消耗 |

## 8.4.8 对应库房出库

按"目的库房"维度统一执行出库：一次出库可能跨多张申领单/请货单，按库房聚合：

| 操作 | 说明 |
|------|------|
| 按库房聚合 | 同一目的库房的多张单据合并出库 |
| 按时间窗 | 在配送时间窗内的所有单据一次性出库 |
| 库存扣减 | 起点库房库存扣减、目的库房在途库存增加 |

## 8.4.10 库房出库汇总

| 汇总维度 | 输出 |
|----------|------|
| 按库房 + 时间段 | 出库金额、件数、品种数 |
| 按商品分类 + 时间段 | 各类商品出库占比 |
| 按目的科室 + 时间段 | 科室耗用排名 |
| 按出库人 + 时间段 | 工作量统计 |

## 8.4.11 补货单查询

| 字段 | 说明 |
|------|------|
| 补货单号 | BH + YYYYMMDD + 序号 |
| 补货类型 | 二级库补货 / 散货货位补货 / 定数包补货 |
| 来源 | 自动请补货单 / 手工补货 / 散货转补货 |
| 状态 | 草稿 / 已审核 / 已出库 / 已收货 / 已关闭 |
| 触发申领单 | 关联反查（散货转补货场景） |
