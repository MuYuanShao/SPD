# 3.1 登录认证

> 所属模块：3. 基础管理模块
> 来源：院内SPD系统产品需求文档.md

## 3.1.1 页面设计

登录页面采用左右分栏卡片式布局：
- **左侧**：系统品牌展示区，包含SPD Logo、系统名称、业务插画
- **右侧**：登录表单区，包含用户名输入、密码输入、业务类型选择、登录按钮
- **背景**：深色渐变背景搭配青绿色几何装饰图形

## 3.1.2 登录流程

```
[用户访问登录页] → [输入用户名和密码] → [选择业务类型（可选）]
    → [前端表单校验] → [调用登录API] → [后端身份认证]
    → [生成JWT Token] → [返回用户信息及权限] → [跳转首页]
```

## 3.1.3 表单校验规则

| 字段 | 校验规则 | 错误提示 |
|------|----------|----------|
| 用户名 | 必填，长度2-20字符 | "请输入用户名" / "用户名长度2-20字符" |
| 密码 | 必填，长度6-20字符 | "请输入密码" / "密码长度6-20字符" |
| 业务类型 | 非必填，默认耗材 | "请选择业务类型" |

## 3.1.4 业务类型

本系统暂不支持业务类型选择，默认统一使用耗材供应链管理模式。

## 3.1.5 安全需求

| 需求项 | 说明 |
|--------|------|
| 密码传输加密 | 前端使用RSA公钥加密密码后传输 |
| 登录次数限制 | 同一IP/账号5分钟内连续失败5次，锁定15分钟 |
| Token机制 | 使用JWT Token，有效期2小时，支持刷新 |
| 验证码 | 连续失败3次后显示图形验证码 |
| 记住密码 | 支持记住用户名（本地存储），禁止明文存储密码 |
