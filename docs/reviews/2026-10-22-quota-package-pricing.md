## 范围边界

此功能提供自动调价及留痕，不新增撤销结算、差额补结或跨浏览器推送流程。价格与基本单位同时变更会中止审批并回滚，须拆分申请。已有结算明细默认锁价，解除锁价必须另走业务流程。

## 审计问题修复

审计确认的锁顺序与逐来源舍入问题均已修复。

- 结算、补单先无锁发现商品范围，按商品 ID 升序锁定商品，再对该范围的来源做当前读；已结状态另行当前读复查。收货创建、修改、审核以及消耗、反消耗的外层入口也提前获取商品锁。审核期间商品范围变化会回滚并要求刷新。
- 按完整套包总额扣除已结金额，再按未结来源数量分摊。四位小数尾差按余数降序、来源 ID 升序分配；跨供应商及分次补单不会重复舍入，也不会覆盖原始成本和已结金额。
- 原审计示例：单价 2.0101、两个批次各 0.5，最终结算为 1.0051 与 1.0050，合计 2.0101。
