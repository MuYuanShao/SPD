院内 SPD Windows 零数据离线部署包
================================
1. 目标系统：64 位 Windows 10/11 或 Windows Server 2019 及以上。
2. 发布包包含应用、前端、JDK 17 和 Windows 服务包装器，不需要安装 Java、Node、Maven 或 Docker。
3. 发布包不包含数据库导出、患者数据、业务数据或固定密码。院方须提前准备 MySQL 8、迁移账号和无 DDL 的运行账号。
4. 解压后右键以管理员身份运行“安装SPD.bat”，按向导录入配置。迁移密码仅用于安装过程，不会保存。
5. 安装成功后服务随 Windows 自动启动，入口为 http://服务器IP:1818/api/（端口可在向导中修改）。
6. 升级前必须完成数据库备份。应用文件可自动回退，数据库迁移只能通过上线前备份恢复。
7. “卸载SPD.bat”默认保留 C:\ProgramData\HospitalSPD 下的配置、日志和附件。
